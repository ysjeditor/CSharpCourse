# C# 핵심 정리: 메모리(Stack/Heap), 참조 타입, `ref` 키워드

## 1. 메모리 구조와 변수의 위치
* **설계도 (`class Player`):** 스택도 힙도 아닌 코드 영역의 형식 정의입니다.
* **스택 (Stack):** 함수 내 지역 변수(`hero`), 매개변수(`p`)가 생성되는 공간입니다. 함수 종료 시 즉시 해제됩니다. (64비트 환경 기준 주소 크기는 **8바이트**)
* **힙 (Heap):** `new` 키워드로 생성한 실제 객체(인스턴스)가 저장되는 공간입니다. (`int` 필드는 **4바이트**)

```csharp
Player hero = new Player { Hp = 100 };
```
* **스택 (`0x1000`):** 변수 `hero` (8바이트) ➔ 힙 주소 **`0x5000`** 저장
* **힙 (`0x5000`):** 실제 `Player` 객체 ➔ 필드 `Hp = 100` (4바이트) 저장

---

## 2. 함수 인자 전달의 대원칙: 값에 의한 전달 (Pass by Value)
C#의 모든 함수는 기본적으로 변수 자체가 아니라 **변수 안에 들어있는 '값'만 새 매개변수 칸에 복사**합니다.

```csharp
static void Change(Player p)
{
    p.Hp = 80;
    p = new Player { Hp = 1 };
}
```
1. **호출 직후 (`Change(hero)`):** 스택 `0x2000`에 새 변수 `p`가 생기고, `hero`(`0x1000`)의 값인 **`0x5000`이 복사**됩니다. (`hero`와 `p`는 서로 다른 독립된 스택 변수)
2. **필드 수정 (`p.Hp = 80`):** `p`가 가리키는 힙 `0x5000`의 `Hp`를 `80`으로 변경합니다. `hero`도 `0x5000`을 가리키므로 `hero.Hp` 역시 `80`이 됩니다.
3. **새 객체 대입 (`p = new Player()`):** 힙 `0x6000`에 새 객체를 만들고, **스택 `0x2000`(`p`)의 값만 `0x6000`으로 덮어씁니다.** `hero`(`0x1000`)는 여전히 `0x5000`을 가리킵니다.
4. **함수 종료:** 지역 변수 `p`는 스택에서 사라지고, `hero.Hp`는 **`80`**으로 유지됩니다.

---

## 3. `ref` 키워드: 참조에 의한 전달 (Pass by Reference)
`ref`는 변수 안의 값(`0x5000`)이 아니라, **원본 변수 자체의 스택 주소(`0x1000`)**를 전달합니다.

```csharp
static void Replace(ref Player p)
{
    p = new Player { Hp = 1 };
}
```
1. **호출 직후 (`Replace(ref hero)`):** 매개변수 `p`(`0x2000`)는 `hero`의 스택 번지 **`0x1000` 자체**를 직접 가리킵니다.
2. **새 객체 대입 (`p = new Player()`):** 힙 `0x7000`에 새 객체를 만든 뒤, `p`가 가리키는 **원본 `hero`(`0x1000`) 칸에 새 주소 `0x7000`을 직접 덮어씁니다.**
3. **함수 종료:** `hero`가 새 객체(`0x7000`)를 가리키게 되어 `hero.Hp`는 **`1`**이 됩니다.

---

## 4. 비교 요약 및 가비지 컬렉터 (GC)

| 구분 | `ref` 없음 (`Change(hero)`) | `ref` 있음 (`Replace(ref hero)`) |
| :--- | :--- | :--- |
| **전달되는 데이터** | `hero` 칸 **안의 값** (`0x5000`, 힙 주소) | `hero` 칸 **자체의 위치** (`0x1000`, 스택 주소) |
| **`p = new ...` 덮어쓰기 위치** | `p`의 스택 칸 (`0x2000`) | `hero`의 스택 칸 (`0x1000`) |
| **함수 종료 후 `hero.Hp`** | `80` (원본 주소 `0x5000` 유지) | `1` (새 주소 `0x7000`으로 교체) |

* **가비지 컬렉터 (GC):** `Replace` 후 기존 `0x5000` 객체처럼 어떤 변수도 가리키지 않게 된 힙 메모리는 **가비지 컬렉터가 자동으로 수거(해제)**합니다.
