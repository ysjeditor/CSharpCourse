# 분을 정수로 입력받아 시간과 분을 표현하지 못했다.
- if (int.TryParse(Console.ReadLine(), out int minutes))를 통해서 숫자를 받아오는 것은 알았지만 더이상 아무것도 하지 못했다.

```markdown
# 내가 모르는것
- 숫자를 양수만 받아야하고 분을 어떻게 시간으로 표현할지 몰랐다.
```

```markdown
# 깨달은점
- TryParse는 문자열을 정수로 바꿔주기 때문에 소숫점을 생각할 필요가없었다.
- minutes를 60으로 나누면 시간이 나오고
- minutes를 60으로 나머지를 구하면 분이 나온다.
- 입력 받은 분을 60으로 나누면 정수부터 시작하기때문에 최소 1이나오기에 분을 알수있었다.
- 뒤에것으로 앞에것을 나누므로 1/60이라고 쉽게 떠올리는 방법을 깨달았다.
```
