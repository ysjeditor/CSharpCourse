# 같은프로젝트에서는 동일 Class가 두 번 선언되면 안된다.
- namespace가 있으면 같은 클래스가 선언될줄 알았는데 되지않았다.

```markdown
# 내가 모르는것
- internal이 무엇인가?
- partial이 무엇인가?
```

```markdown
# 깨달은점
- 같은 프로젝트 안에는 단일 클래스만 이썽야하고
- 분리하려면 namespace를 달리하거나 partial을 사용하여 사용할 수 있다.
- internal은 같은 프로젝트 안에서만 사용할 수 있도록 하는 보안 문법이며 따로 지정하지 않을 시 C#에서는 자동적으로 internal이 적용된다.
- partial은 코드가 길어졌을 때 Class 앞에 partial을 붙이면 서로 떨어져 있더라도 같은 Class로써작동할수 있도록해준다.
```

```markdown
# 추가적인 궁금중
- 그렇다면 internal partial Class Program 처럼 internal과 partial을 붙여도되는지 
-> 조사 결과 가능했고 이것이 일반적이다.
```
