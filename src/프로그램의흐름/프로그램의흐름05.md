# static void Main()과 static void Main(string[] args)의 차이를 모르겠다.
- static void Main()은 코드가 시작되는 시작점이라고 알고있지만
- static void Main(string[] args)는 어떤 것이 다른지 모르겠다.

```markdown
- static void Main(string[] args)에서 args는 arguments의 약자로 인자를 의미함.
- 하지만 정확히 어떤 곳에서 사용되는지 아직 이해를 잘 못하겠다.
```

# 내가 이해하고 있는 범위
- static void Main()는 코드의 시작점이며 프로젝트에 단 하나의 Main 메서드만 존재하여야한다.
- static void Main(string[] args)도 프로젝트에 단 하나의 Main 메서드만 존재해야할 것 같다.
- 하지만 이것을 어떻게 사용하는지 내가 설명할 수준이 되지않는다.

# apple banana -windowed "hello world"를 출력해보았다.
- 솔루션 탐색기의 프로젝트 우클릭 -> 속성 -> 디버그 -> 일반 -> 명령줄 인수에 apple banana -windowed "hello world" 입력
- 그랬더니 띄워쓰기 한 칸마다 0부터 ++ 되어 배열로 순서가 나왔으며 단어가 인자로 받아서 출력되었다.
