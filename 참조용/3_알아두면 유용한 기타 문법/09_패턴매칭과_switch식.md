# 09. 패턴 매칭과 switch 식

## 조건 확인과 값 추출을 함께 하기

`object`로 받은 값이 문자열인지 확인한 뒤 문자열로 변환하여 길이를 읽는 작업을 생각해봅시다. **형식 패턴** `value is string text`는 자료형 확인과 사용할 변수 선언을 함께 표현합니다. 일치하는 경로에서 `text`를 사용할 수 있습니다.

패턴 매칭은 형식뿐 아니라 값·프로퍼티·범위를 검사할 수 있습니다. C# 9의 관계 패턴과 `and`, `or`, `not`은 여러 조건을 결합합니다. 일반적인 bool 연산자 `&&`, `||`, `!`와 문법이 쓰이는 위치를 구별하세요.

## switch 문과 switch 식

switch 문은 분기별로 여러 작업을 수행할 때 사용합니다. **switch 식은 입력에 대응하는 결과값 하나를 만드는 표현**입니다. 각 항목은 패턴, `=>`, 결과식으로 구성되며 `_`는 나머지 경우에 대응합니다. 위에서부터 검사하므로 순서가 중요합니다.

## 실행 예제

```csharp
using System;

class Program
{
    static void Main()
    {
        object value = "안녕하세요";
        if (value is string text)
            Console.WriteLine(text.Length);

        int score = 85;
        string result = score switch
        {
            < 0 or > 100 => "범위 오류",
            >= 90 => "A",
            >= 60 => "합격",
            _ => "재도전"
        };
        Console.WriteLine(result);
    }
}
```

```text
5
합격
```

`>= 60`은 앞의 조건에 해당하지 않은 점수에 적용됩니다. 따라서 이 예제에서는 유효 범위이며 90 미만인 값만 도달합니다. `if`를 각각 독립적으로 작성한 것과 처리 방식이 다릅니다.

## 실수 점검과 연습

- `value is string text`는 null일 때 일치하지 않습니다. 반대로 `is null`은 null을 검사하는 패턴입니다.
- 넓은 패턴을 앞에 두면 뒤의 좁은 패턴에 도달할 수 없을 수 있습니다.
- `and`, `or`는 패턴 안의 키워드이지 임의의 bool 식 어디서나 바꿔 쓸 수 있는 기호가 아닙니다.
- -1, 59, 60, 89, 90, 101을 넣고 결과를 확인하세요. 등급 B를 추가할 때 조건 순서를 먼저 정합니다.
