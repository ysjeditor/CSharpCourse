# 10. 튜플·분해·인덱스·범위

## 관련된 결과 여러 개 돌려주기

최솟값과 최댓값처럼 한 번의 계산에서 두 결과가 필요할 수 있습니다. **튜플**은 여러 값을 잠시 묶는 값 형식입니다. 반환형을 `(int min, int max)`로 적으면 결과의 의미도 이름으로 설명할 수 있습니다.

반환값을 `(int min, int max) = ...`로 나누어 받는 것을 **분해(Deconstruction)**라고 합니다. 필요 없는 요소는 `_`로 버릴 수 있습니다. 데이터가 오래 저장되거나 여러 규칙과 동작이 붙으면 의미 있는 이름의 클래스나 구조체로 정의하는 편이 낫습니다.

## 뒤에서 접근하고 구간 선택하기

배열이나 문자열에서 `^1`은 뒤에서 첫 번째 위치입니다. `^0`은 끝 다음 위치이므로 요소 하나를 읽는 유효 인덱스가 아닙니다. 범위 `start..end`는 **시작을 포함하고 끝을 제외**합니다.

| 표현 | 의미 |
| --- | --- |
| `values[^1]` | 마지막 요소 |
| `values[1..3]` | 인덱스 1과 2의 구간 |
| `values[..2]` | 처음 두 요소 |
| `values[2..]` | 인덱스 2부터 끝까지 |

## 실행 예제

```csharp
using System;

class Program
{
    static void Main()
    {
        int[] values = { 4, 9, 2 };
        (int min, int max) = FindRange(values);
        Console.WriteLine($"{min},{max}");
        Console.WriteLine(values[^1]);
        Console.WriteLine(string.Join(",", values[1..]));
        Console.WriteLine("CSharp"[..2]);
    }

    static (int min, int max) FindRange(int[] values)
    {
        if (values.Length == 0) throw new ArgumentException("빈 배열입니다.", nameof(values));
        int min = values[0], max = values[0];
        foreach (int value in values)
        {
            if (value < min) min = value;
            if (value > max) max = value;
        }
        return (min, max);
    }
}
```

## 실수 점검과 연습

- 튜플 요소 이름만 다르다고 서로 전혀 다른 튜플 자료형이 되는 것은 아닙니다.
- 배열의 범위 추출은 새 배열을 만듭니다. 항상 원본과 저장 공간을 공유하는 뷰라고 생각하지 마세요.
- 일반 `List<T>`는 `^`를 사용한 요소 접근이 가능하지만 배열과 같은 범위 슬라이싱을 그대로 지원한다고 가정하지 않습니다. `GetRange` 등 제공하는 API를 확인합니다.
- `^0`으로 요소를 읽거나 비어 있는 배열을 전달하면 왜 실패하는지 설명하세요. 예제의 빈 배열 예외는 11단원에서 배웁니다.
