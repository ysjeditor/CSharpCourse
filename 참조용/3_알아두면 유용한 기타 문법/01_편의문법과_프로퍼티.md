# 01. 편의 문법과 프로퍼티

## 같은 의미를 더 읽기 쉽게 표현하기

입문 단계에서는 자료형과 실행 순서를 눈으로 확인하는 것이 중요합니다. 이후에는 반복되는 표현을 줄여 의도를 드러내는 문법을 배웁니다. 짧게 썼다는 이유만으로 더 좋은 코드는 아니며, **읽는 사람이 실제 자료형과 동작을 알 수 있는지**가 기준입니다.

| 기능 | 읽는 방법 | 도입 시점 |
| --- | --- | --- |
| `var` | 초기값으로 지역 변수의 자료형을 컴파일 시 결정 | C# 3 |
| 객체·컬렉션 초기화 | 생성 시 프로퍼티나 초기 요소 지정 | C# 3 |
| 자동 구현 프로퍼티 | 저장 공간 접근을 `get`, `set`으로 정의 | C# 3 |
| 프로퍼티 초기값 | 객체가 생성될 때 사용할 시작값 지정 | C# 6 |
| 문자열 보간 | `$"이름: {name}"`에서 식의 값을 문자열에 삽입 | C# 6 |
| `nameof` | 코드 식별자의 이름을 문자열로 얻음 | C# 6 |
| 식 본문 `=>` | 짧은 멤버의 구현을 하나의 식으로 표현 | C# 6~7 |
| `out var`, `_` | 출력 매개변수의 변수 선언 또는 결과 버리기 | C# 7 |
| 대상 형식 기반 `new()` | 왼쪽 등 문맥에서 생성할 형식을 결정 | C# 9 |

## 프로퍼티와 값 변경 권한

`public int Score { get; private set; }`은 외부에서 읽을 수 있지만 직접 바꿀 수 없는 프로퍼티입니다. 클래스 내부의 메서드에서 규칙을 검사한 다음 변경할 수 있습니다. `public string Name { get; set; }`은 외부에서도 변경할 수 있어 객체 초기화 구문으로 값을 넣을 수 있습니다.

객체 초기화는 생성자 실행 후 프로퍼티에 값을 대입합니다. 모든 초기화가 하나의 검증된 작업으로 처리되는 것은 아니므로, 반드시 필요한 값은 생성자에서 받는 설계도 고려합니다.

## 실행 예제

```csharp
using System;
using System.Collections.Generic;

class Program
{
    static void Main()
    {
        var student = new Student { Name = "민수" };
        List<int> scores = new() { 70, 80 };
        if (int.TryParse("90", out var score))
            student.SetScore(score);
        Console.WriteLine($"{student.Name}: {student.Score}점");
        Console.WriteLine($"{nameof(Student.Score)} / {scores.Count}개");
    }
}

class Student
{
    public string Name { get; set; } = "미등록";
    public int Score { get; private set; }
    public void SetScore(int score) => Score = score;
}
```

```text
민수: 90점
Score / 2개
```

`var student`의 자료형은 `Student`이며 다른 자료형의 값을 나중에 마음대로 넣을 수 없습니다. `out var score`도 메서드의 매개변수 형식에 따라 `int`로 정해집니다. 반환값만 필요하고 변환 결과는 필요 없다면 `int.TryParse("90", out _)`처럼 결과를 버릴 수 있습니다.

## 실수 점검과 연습

- `var value;`처럼 초기값 없이 사용할 수 없습니다. `var`는 필드나 매개변수의 일반적인 자료형 표기로 사용하지 않습니다.
- `=>`는 여기서 식 본문 멤버입니다. 람다식과 모양이 같아도 선언 위치와 역할을 확인하세요.
- `nameof`는 값이 아니라 이름입니다. `nameof(student)`는 학생 이름인 민수가 아닙니다.
- `SetScore`에 0~100 범위 검사를 넣어보세요. 검증 실패 시 어떻게 알릴지는 예외 처리 단원과 연결해 결정합니다.
