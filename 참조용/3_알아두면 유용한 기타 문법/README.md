# 알아두면 유용한 기타 문법

변수·조건문·반복문·배열·클래스·기본 컬렉션을 배운 뒤 읽는 **C# 후속 학습 문서**입니다. 두 강의 트랙이 공통으로 사용할 수 있도록 정리했습니다.

## 웹 교재 열기

[index.html](index.html)을 더블 클릭하면 13개 단원을 브라우저에서 읽을 수 있습니다. 목차, 제목·본문 검색, 이전·다음 이동, 코드 복사, 밝은·어두운 화면, 단원별 학습 완료 표시를 제공합니다. 인쇄/PDF 버튼은 없습니다.

HTML 안에 본문·스타일·스크립트를 모두 담아 파일 하나만 옮겨도 사용할 수 있습니다. 문서 읽기에는 Python, .NET, 서버, 인터넷이 필요하지 않습니다. 예제 실행은 별도의 Visual Studio 콘솔 프로젝트에서 진행합니다. 학습 완료 표시는 이 교재 전용 브라우저 저장 키를 사용하며 브라우저·파일 위치에 따라 유지되지 않을 수 있습니다.

## 학습 범위

Unity 6.3 LTS와 6.6의 기본 C# 9 지원 범위를 기준으로, 일반 C#에서도 사용하는 문법과 .NET 기초 기능을 선정했습니다. 인터페이스와 예외는 객체지향 설계와 오류 처리의 기반으로, 리플렉션은 메타데이터를 다루는 후반 주제로 포함합니다.

**코루틴·이터레이터 실습, Unity Awaitable, 엔진 생명주기 콜백, Unity 전용 이벤트 API는 다루지 않습니다.** 비동기는 `Task`, `async`, `await`, 취소 토큰을 사용한 일반 C# 예제로 학습합니다.

## 실습 방법

각 문서의 C# 코드 블록은 **하나씩 독립적으로 실행하는 완성 예제**입니다. 별도의 C# 콘솔 프로젝트에서 `Program.cs` 전체를 바꿔 실행합니다. 모든 예제는 명시적인 `Program.Main` 진입점을 사용합니다. 여러 문서의 코드를 한 파일에 이어 붙이지 마세요.

설명 → 예제 실행 → 실행 순서 확인 → 실수 점검 → 직접 수정의 순서로 학습합니다. 아래 예제들은 `System`과 기본 .NET 라이브러리를 사용하며 외부 패키지가 필요하지 않습니다. `검증.py`는 설치된 .NET SDK로 코드 블록을 C# 9 문법으로 빌드하고 예상 출력과 비교합니다. 문법 검증은 실제 엔진과 모든 빌드 플랫폼에서의 동작 검증을 대신하지 않습니다.

## 호환성 기준

- C# 9 이하의 문법을 사용합니다. `Action`, `Task`, LINQ, Reflection은 문법 자체가 아니라 라이브러리 기능도 포함합니다.
- `record`·`init`은 기본 과정에서 제외합니다. C# 10 이후의 파일 범위 네임스페이스, `required`, 기본 생성자, 컬렉션 식도 사용하지 않습니다.
- 기본 인터페이스 구현과 정적 추상 인터페이스 멤버는 제외하고, 전통적인 추상 멤버 계약을 학습합니다.
- 리플렉션의 형식 조회와 런타임 코드 생성은 구분합니다. AOT·코드 제거 환경에서는 조회 대상 보존과 실제 빌드 확인이 필요하며, `Reflection.Emit`은 이 과정에 포함하지 않습니다.

## 교재 유지관리

번호로 시작하는 Markdown 파일을 수정한 뒤 `python build.py`를 실행하면 HTML을 갱신합니다. 생성할 때는 옆의 `입문웹교재` 폴더에 있는 변환 함수와 스타일을 재사용합니다. 기존 입문웹교재 파일은 수정하지 않습니다. 배포된 index.html을 읽을 때는 원본 폴더들이 필요하지 않습니다.

`python 검증.py`로 예제의 컴파일과 출력을 검사합니다. 이 명령은 기존 입문웹교재 실행기를 수정하지 않습니다. 예제 수정 시 같은 문서의 `text` 블록에 예상 출력도 갱신하세요.
