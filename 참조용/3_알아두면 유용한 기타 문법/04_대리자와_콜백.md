# 04. 대리자와 콜백

## 메서드를 전달하고 나중에 호출하기

계산을 수행하는 코드는 같지만 완료 후 무엇을 할지는 사용자가 정하고 싶을 수 있습니다. 이때 호출 가능한 메서드를 값처럼 전달하는 수단이 **대리자(Delegate)**입니다. 전달한 함수를 특정 시점에 호출하는 사용 방식은 **콜백(Callback)**이라고 합니다.

대리자는 매개변수와 반환형이 일치하는 메서드를 참조합니다. `Calculate`는 사용자 정의 대리자 이름이고 `Add`는 그 대리자에 넣을 메서드입니다. `Calculate operation = Add;`는 호출 결과를 저장하는 것이 아니라 호출할 대상을 연결합니다.

## 실행 예제

```csharp
using System;

delegate int Calculate(int left, int right);

class Program
{
    static void Main()
    {
        Calculate operation = Add;
        Console.WriteLine(operation(3, 4));
        Action<string> notify = Console.WriteLine;
        Func<int, int, int> sum = Add;
        Predicate<int> isPositive = IsPositive;
        notify($"합계: {sum(2, 5)}");
        Console.WriteLine(isPositive(1));
    }

    static int Add(int left, int right) { return left + right; }
    static bool IsPositive(int value) { return value > 0; }
}
```

```text
7
합계: 7
True
```

## 라이브러리 대리자 읽기

| 형식 | 의미 |
| --- | --- |
| `Action` | 입력 없음, 반환값 없음 |
| `Action<string>` | 문자열 하나 입력, 반환값 없음 |
| `Func<int, int>` | 정수 하나 입력, 정수 반환 |
| `Func<int, int, bool>` | 정수 둘 입력, bool 반환. 마지막 형식이 반환형 |
| `Predicate<int>` | 정수 하나를 검사하여 bool 반환 |

`Action`이나 `Func`는 새로운 문법이 아니라 .NET이 제공하는 대리자 형식입니다. 고유한 의미를 이름에 표현해야 하면 사용자 정의 대리자를 선택할 수 있습니다.

## 실수 점검과 연습

- `operation = Add()`는 호출입니다. 위 예제의 매개변수 없는 호출은 성립하지 않으며 대리자를 연결하는 표현과 다릅니다.
- 반환값이 있는 대리자에 메서드를 여러 개 연결하면 일반적인 호출 결과는 마지막 대상의 반환값입니다. 합계가 자동 집계되는 것은 아닙니다.
- `Multiply`를 추가하고 같은 대리자 변수의 호출 대상을 바꾸세요. 호출하는 쪽의 코드는 그대로 두고 결과가 달라지는지 확인합니다.
