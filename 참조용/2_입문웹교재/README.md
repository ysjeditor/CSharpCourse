# C# 입문 웹교재

1. `index.html`을 더블 클릭하면 브라우저에서 열립니다. 설치와 서버가 필요하지 않습니다.
2. 왼쪽 목차로 단원을 고르고, 코드 예제는 Visual Studio 또는 아래의 웹 실습창에서 실행합니다.
3. 검색은 단원 제목과 본문을 대상으로 목차를 필터링합니다.
4. 학습 완료 표시는 현재 브라우저의 로컬 저장소를 사용합니다. 파일 이동이나 브라우저에 따라 유지되지 않을 수 있습니다.

## 웹 코드 실습 시작

필수 환경: Python 3.10 이상, .NET SDK 6 이상. 별도 Python 패키지나 NuGet 패키지를 설치할 필요가 없습니다. Node.js는 개발 검증에만 사용합니다.

### 다른 PC에 배포

1. ZIP을 **폴더 전체로 압축 해제**하세요. ZIP 미리보기 안에서 BAT을 실행하지 않습니다.
2. 처음에는 `setup.bat`을 실행합니다. Python과 .NET SDK를 검사하고, 없는 도구만 WinGet으로 설치합니다. 기본 설치 대상은 Python 3.13과 .NET SDK 10입니다.
3. 설치가 끝나면 실제 C# 코드 컴파일·실행·한글 입출력을 검사합니다. 성공 메시지를 확인하세요.
4. 이후에는 `실습시작.bat`만 실행하면 됩니다. 실행할 때도 환경을 검사하며, Python은 PATH뿐 아니라 런처와 설치 경로에서도 찾습니다.

설치 시 인터넷 연결과 설치 권한이 필요할 수 있습니다. Windows의 설치 승인 창이 나오면 직접 확인하세요. WinGet이 없으면 공식 다운로드 주소를 안내합니다. 설치가 완료된 PC는 인터넷 없이 교재와 기본 실습을 사용할 수 있습니다. Visual Studio는 웹 실습 실행에 필수가 아닙니다.

대상은 Windows 10/11입니다. 운영체제 버전별 공식 지원 여부, 학교 PC의 설치 제한, 보안 프로그램, 손상된 SDK, 포트 충돌까지 모든 PC의 정상 실행을 보장하지는 않습니다. 회사·학교의 PowerShell 실행 정책이 강제된 PC는 관리자의 지원이 필요할 수 있습니다. BAT에서 지정하는 실행 정책은 해당 PowerShell 프로세스에만 적용하며 시스템 정책을 영구 변경하지 않습니다.

도구를 설치하지 않고 검사만 하려면 `powershell -NoProfile -ExecutionPolicy Bypass -File .\환경설정.ps1 -Mode Check`, 실제 컴파일까지 검사하려면 `-Mode Verify`를 사용합니다. 설치 완료 여부는 탐지 결과뿐 아니라 Verify 성공으로 확인하세요.

교재를 수정한 뒤 `python package.py`를 실행하면 상위 폴더에 `입문웹교재-배포.zip`을 생성합니다. Python 캐시와 로그는 포함하지 않습니다. Markdown이나 실습 내용을 바꿨다면 먼저 `python build.py`로 HTML을 갱신하세요.

1. 이 폴더의 `실습시작.bat`을 더블 클릭합니다.
2. 자동으로 열린 `http://127.0.0.1:8765`에서 교재를 읽습니다.
3. 각 단원 아래의 Program.cs 입력창에서 작성하고 **실행** 또는 **채점하기**를 누릅니다.
4. 실행은 직접 입력한 데이터로 한 번 실행합니다. 채점은 문제에 지정된 모든 입력으로 검사합니다.
5. 종료하려면 서버 창에서 Ctrl+C를 누릅니다.

명령줄에서는 `python server.py`를 사용합니다. 포트 충돌 시 `python server.py --port 8766`으로 실행합니다. 브라우저를 자동으로 열지 않으려면 `--no-browser`를 붙입니다.

컴파일 오류의 줄을 편집창에서 선택하고 오류 코드와 메시지를 보여줍니다. 오답은 테스트별 입력·예상 출력·실제 출력을 보여줍니다. 실행 중 예외, 테스트당 3초 시간 제한과 32KB 출력 제한을 구분합니다. 컴파일 제한은 45초입니다. 줄바꿈 형식과 출력 끝의 줄바꿈만 무시하며 공백과 대소문자는 구분합니다. 채점은 출력 결과를 검사하므로 특정 문법을 사용했는지까지 증명하지는 않습니다.

작성 코드는 단원별로 브라우저에 저장합니다. 초기 코드 복원 전 확인을 요청합니다. Tab은 공백 4칸, Ctrl+Enter는 채점입니다. 직접 HTML 파일을 열면 읽기와 편집만 가능하며 실행 버튼에는 서버 시작 안내를 표시합니다.

### 실행 범위

이 실행기는 **학생 본인의 PC에서 본인이 작성한 연습 코드를 실행하는 용도**입니다. 코드는 로그인한 사용자 권한으로 동작하며 파일·네트워크 접근을 격리하지 않습니다. 시간·출력 제한은 무한 반복 대응 기능이며 보안 샌드박스는 아닙니다. 서버는 127.0.0.1에만 바인딩하고 동일 출처와 실행 토큰을 검사합니다. 공용 서버에 올리거나 타인이 제출한 코드를 실행하는 서비스로 사용하지 마세요.

컴파일 결과는 임시 폴더에 생성 후 삭제합니다. 외부 패키지 소스를 사용하지 않습니다. SDK 선택은 설치된 가장 높은 메이저 버전 기준이며 해당 SDK의 기본 언어 버전을 사용합니다.

## 교재 수정

`교재.md`를 수정한 뒤 이 폴더에서 `python build.py`를 실행합니다. 생성된 HTML에는 교재, 스타일과 스크립트가 모두 포함되어 HTML 파일 하나만 전달할 수 있습니다.

지원하는 Markdown은 단원 제목(`##`), 소제목(`###`~`######`), 문단, **굵게 표시**, 인라인 코드, 순서 있는 목록·없는 목록, 표, 인용문, 코드 블록입니다. 중첩 목록 등 전체 Markdown 명세를 지원하는 범용 변환기는 아닙니다. `힌트와 해설`은 접힌 해설로 표시되며 다음 큰 소제목에서 닫힙니다. `csharp` 코드 블록은 C# 예제, `text` 코드 블록은 실행 결과로 표시합니다.

개념 설명은 일상적인 상황 → 용어와 필요성 → 문법 해석 → 처리 순서 → 실수 확인의 흐름으로 작성합니다. 긴 단원은 `####` 소제목으로 나누고 자료형과 비교 정보는 표로 정리합니다. 읽기 스타일은 `reading.css`에서 수정합니다. 개념 설명의 코드 조각과 `Program.cs` 전체를 바꿔 실행하는 완성 예제를 구분하세요.

실습 문제·초기 코드·입출력 테스트·힌트는 `exercises.json`에서 수정합니다. `solution`은 개발 검증용 정답이며 HTML에 포함하지 않습니다. 실행기는 같은 JSON에서 테스트를 읽으므로 수정 후 `python build.py`를 실행하고 서버를 재시작하세요. 편집기와 채점 UI는 `practice.js`, 스타일은 `practice.css`를 수정합니다.

검증: `python test_runner.py`로 14개 과제의 정답, 오답, 컴파일 오류, 실행 예외, 시간·출력 제한, 사용자 입력과 생성된 JavaScript 문법을 검사합니다.

## 구성

14개 단원으로 환경 설정, 변수, 입력과 연산, 조건문, 메뉴, 반복문, 배열, 메서드, 클래스, 캡슐화와 참조, 컬렉션, 디버깅, 종합 과제를 다룹니다. 기존 24강 목차의 개념을 독학용 14개 읽기 단원으로 묶었습니다. 상속·인터페이스는 후속 심화 주제로 남겼습니다.
