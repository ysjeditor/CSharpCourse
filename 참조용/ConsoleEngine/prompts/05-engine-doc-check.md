> 붙여 넣을 것: README.md의 엔진 5분 시작 가이드, docs/engine-guide.md, 공개 API 목록과 XML 주석

## 답을 받은 뒤 사람이 확인할 것

- 실제 사용자인 시스템 담당에게 가이드만 보고 따라 해 보게 합니다. 엔진 PR의 리뷰어도 시스템 담당입니다.
- 지적이 맞는지 엔진 코드를 보고 확인합니다. 문서와 코드가 다르면 무엇이 맞는지 정하고 둘 중 하나를 고칩니다.
- 5분 시작 가이드의 예제는 직접 새 프로젝트에 복사해 Ctrl+F5로 실행해 봅니다.
- 고친 내용은 CHANGELOG.md에 남기고, 문서는 엔진 담당이 직접 씁니다.
