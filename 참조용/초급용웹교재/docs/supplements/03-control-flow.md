# 3장. 제어문

### 학습 목표

조건·반복·분기의 실행 순서를 추적하고 종료 조건을 작성합니다.

### 개념 읽기

#### 제어문이란?

프로그램은 보통 위에서 아래로 실행됩니다. **제어문**은 조건에 따라 실행할 부분을 고르거나 같은 처리를 반복하도록 이 흐름을 바꿉니다. 먼저 조건문인 if와 switch를 익히고, 반복문과 분기문으로 확장합니다. 아래 기본 구조 예시는 각각 따로 실행하는 코드입니다.

#### if — 조건이 참일 때 실행하기

`if`는 괄호 안의 조건식이 `true`일 때 중괄호 안의 문장을 실행합니다. 조건식은 `bool`이어야 합니다. `else`는 조건이 거짓일 때 실행할 부분이며 필요하지 않으면 생략합니다.

```csharp
int score = 75;                  // 판단할 값
if (score >= 60)                 // 조건식: 60 이상인가?
{
    Console.WriteLine("합격");     // true일 때 실행할 블록
}
else
{
    Console.WriteLine("재도전");   // false일 때 실행할 블록
}
// 선택한 블록이 끝나면 여기부터 계속 실행합니다.
```

score가 75이면 합격만 출력합니다. 59로 바꾸면 재도전만 출력합니다. `>=`는 경계값 60을 포함하고 `>`는 포함하지 않습니다. 두 조건을 모두 만족해야 하면 `&&`, 하나 이상 만족하면 되면 `||`를 사용합니다.

#### else if — 여러 조건을 순서대로 검사하기

세 가지 이상의 경로가 필요하면 if 뒤에 else if를 이어 씁니다. 조건은 위에서 아래로 검사하며 처음 참이 된 블록 하나만 실행합니다. 나머지 조건은 검사하지 않고 구조를 빠져나옵니다.

```csharp
int score = 85;
if (score < 0 || score > 100)     // 먼저 잘못된 범위를 거절
{
    Console.WriteLine("입력오류");
}
else if (score >= 90)            // 앞 조건이 false일 때 검사
{
    Console.WriteLine("A");
}
else if (score >= 60)            // 앞의 모든 조건이 false일 때 검사
{
    Console.WriteLine("통과");
}
else                            // 위 조건이 모두 false인 경우
{
    Console.WriteLine("재도전");
}
```

85는 통과입니다. 60 이상을 90 이상보다 먼저 검사하면 95도 앞쪽 블록에서 처리됩니다. 넓은 조건과 좁은 조건의 순서를 확인하세요. 서로 독립된 if를 여러 번 쓰면 각 조건을 따로 검사하므로 여러 블록이 실행될 수 있습니다.

#### switch 문 — 정해진 값에 따라 기능 고르기

메뉴처럼 선택할 값이 정해져 있을 때는 switch 문으로 분기를 나란히 적을 수 있습니다. 괄호 안의 값과 일치하는 case의 본문을 실행합니다. default는 일치하는 case가 없을 때의 처리이며 생략할 수 있습니다.

```csharp
string menu = "2";               // switch가 확인할 대상 값
switch (menu)
{
    case "1":                   // menu가 문자열 "1"인 경우
        Console.WriteLine("시작");
        break;                  // switch 문을 빠져나감
    case "2":                   // menu가 문자열 "2"인 경우
        Console.WriteLine("도움말");
        break;
    default:                    // 일치하는 case가 없는 경우
        Console.WriteLine("없는 메뉴");
        break;
}
// break 뒤에는 switch 다음 문장으로 이동합니다.
```

예제는 도움말을 출력합니다. 문자열 `"2"`와 정수 `2`는 다르므로 대상 값과 case 값의 형식을 맞춥니다. C#에서는 일반적인 비어 있지 않은 case가 다음 case로 암묵적으로 이어지지 않습니다. break나 return 등으로 분기의 흐름을 끝내야 합니다.

#### switch 식 — 선택한 결과를 값으로 만들기

switch **문**은 분기에서 여러 문장을 실행할 때, switch **식**은 조건에 맞는 값 하나를 구할 때 사용합니다. 식은 `대상 switch { 패턴 => 결과, ... }`의 형태입니다. 각 항목은 쉼표로 구분하고 전체 대입문 끝에는 세미콜론을 붙입니다.

```csharp
int score = 85;
string grade = score switch      // 선택한 문자열을 grade에 대입
{
    < 0 or > 100 => "입력오류",   // 관계 패턴을 or로 연결
    >= 90 => "A",               // 패턴 => 선택할 값
    >= 60 => "통과",
    _ => "재도전"                // 나머지 모든 경우
};
Console.WriteLine(grade);         // 통과
```

패턴도 위에서 아래로 확인합니다. `_`는 어떤 값이든 받는 버림 패턴이므로 보통 마지막에 둡니다. 가능한 입력을 빠뜨리지 않도록 나머지 경우를 처리하세요.

#### 조건을 검사하는 순서

점수 등급은 같은 점수를 여러 등급으로 처리하면 안 됩니다. `if / else if / else`는 위에서 아래로 검사해 처음 참인 경로 하나를 선택합니다. 먼저 0~100 범위를 검사하고, 유효한 점수에서 높은 기준부터 비교합니다. 서로 독립된 `if`는 여러 블록이 모두 실행될 수 있습니다.

정해진 메뉴에는 `switch` 문을 사용할 수 있습니다. 각 `case`는 `break`, `return` 같은 제어 이동으로 끝냅니다. 하나의 결과값을 고를 때는 `switch` 식도 유용합니다. `score switch { >= 90 => "A", >= 60 => "통과", _ => "재도전" }`에서 `_`는 나머지 경우입니다. 관계 패턴은 입력값을 기준값과 비교합니다.

#### 반복을 고르는 기준

| 문법 | 검사 시점 | 적합한 상황 |
| --- | --- | --- |
| `for` | 매 회차 본문 전 | 시작·끝·변경이 명확함 |
| `while` | 본문 전 | 상태가 유지되는 동안 처리 |
| `do-while` | 본문 후 | 최소 한 번 처리 후 판단 |
| `foreach` | 다음 요소가 있을 때 | 컬렉션의 각 요소 읽기 |

`for`는 초기화 한 번 → 조건 검사 → 본문 → 증감 → 조건 검사 순입니다. `do-while`도 조건이 계속 참이면 끝나지 않습니다. 반복 횟수와 종료 상태를 먼저 적고 코드를 작성하세요.

#### for와 foreach — 횟수 또는 요소를 기준으로 반복하기

```csharp
// for (초기화; 계속할 조건; 한 회차 뒤 변경)
for (int i = 0; i < 3; i++)      // i는 0, 1, 2 순서
{
    Console.WriteLine(i);        // 반복할 본문
}

int[] scores = { 70, 80, 90 };
foreach (int score in scores)    // 각 요소를 score로 받아 처리
{
    Console.WriteLine(score);    // 인덱스 없이 값을 읽음
}
```

for의 초기화는 처음 한 번만 실행합니다. foreach의 반복 변수에는 매 회차의 요소가 들어옵니다. 요소 위치를 이용해 배열을 수정할 때는 인덱스가 있는 for가 편리합니다.

#### while과 do-while — 조건을 기준으로 반복하기

```csharp
int count = 3;
while (count > 0)                // 본문 실행 전에 조건 검사
{
    Console.WriteLine(count);    // 3, 2, 1 출력
    count--;                    // 종료 조건에 가까워지도록 변경
}

int attempt = 0;
do
{
    Console.WriteLine(attempt);  // 조건이 false여도 첫 회차는 실행
    attempt++;
} while (attempt < 1);           // 본문 뒤 조건 검사, 끝의 ; 필요
```

while은 처음 조건이 거짓이면 한 번도 실행하지 않습니다. do-while은 본문을 먼저 실행하므로 최소 한 번 실행합니다.

#### 흐름을 바꾸는 세 문장

`break`는 가장 가까운 반복문 또는 `switch`를 끝냅니다. `continue`는 현재 회차의 남은 부분을 건너뛰고 다음 회차로 갑니다. `return`은 현재 함수나 메서드를 끝냅니다. 중첩 반복문에서 `break` 하나가 모든 반복을 종료하지는 않습니다. `while`에서 증감을 `continue` 뒤에 놓으면 종료 상태에 도달하지 못할 수 있습니다.

```csharp
for (int i = 1; i <= 5; i++)
{
    if (i == 2) continue;        // 2의 출력은 건너뛰고 증감식으로 이동
    if (i == 4) break;           // 반복 전체 종료: 4와 5는 출력하지 않음
    Console.WriteLine(i);        // 1, 3 출력
}
Console.WriteLine(IsPassed(60)); // True

static bool IsPassed(int score)
{
    if (score < 0) return false; // 현재 함수 호출 종료
    return score >= 60;          // 결과를 호출한 곳으로 반환
}
```

### 따라 하기

```csharp
using System;

int sum = 0;
for (int i = 1; i <= 6; i++)
{
    if (i % 2 != 0) continue;
    sum += i;
}
Console.WriteLine(sum);
int score = 85;
string grade = score switch
{
    >= 90 => "A",
    >= 60 => "통과",
    _ => "재도전"
};
Console.WriteLine(grade);
```

### 결과 확인

```text
12
통과
```

1·3·5는 합산을 건너뛰고 2·4·6을 더합니다. `continue` 뒤에도 `for`의 증감식은 수행됩니다.

### 자주 하는 실수

`if (조건);`은 빈 문장을 본문으로 만듭니다. 반복의 `<`와 `<=`도 구분하세요. `switch` 내부의 `break`가 바깥 메뉴 반복까지 종료한다고 생각하지 마세요.
