# 1장. 개발 환경 구축

### 학습 목표

- VS Code, .NET SDK, 소스 코드와 실행 결과를 구분합니다.
- 단일 C# 파일과 웹 실습창에서 첫 프로그램을 실행합니다.
- 설치와 컴파일 오류의 확인 순서를 익힙니다.

### 개념 읽기

#### 개발 도구의 역할

**Visual Studio Code**는 코드를 작성하는 편집기이고 **.NET SDK**는 C# 코드를 빌드하고 실행하는 도구입니다. 실행 환경만 제공하는 Runtime과 구분하세요. 코드를 적는 것과 실행하는 것은 별도 단계입니다. 저장한 소스 코드를 빌드하고 실행해야 결과가 나옵니다.

| 도구·파일 | 역할 | 확인 방법 |
| --- | --- | --- |
| VS Code | 코드 작성과 편집 | 학습 폴더와 파일 열기 |
| Microsoft의 C# 확장 | 문법 분석과 편집 지원 | VS Code 확장 화면 |
| .NET 10 SDK 이상 | 빌드와 실행 | `dotnet --list-sdks` |
| Python 3.10 이상 | 로컬 웹 실행기 | `python --version` |
| `lesson.cs` | C# 소스 파일 | 저장 후 실행 |

#### 설치하고 확인하기

1. VS Code와 .NET 10 SDK를 설치합니다. 이미 설치되어 있다면 먼저 버전을 확인합니다.
2. VS Code에서 학습용 폴더를 열고 Microsoft의 C# 확장을 설치합니다.
3. 새 터미널에서 다음 명령을 실행합니다.
4. SDK가 나타나면 lesson.cs 파일을 만들고 아래 기본 구조를 저장합니다.

```powershell
dotnet --list-sdks  # Runtime이 아니라 SDK 설치 여부 확인
python --version   # 웹 실행기의 Python 버전 확인
```

웹 실습만 사용할 때 VS Code는 필수가 아닙니다. 이 폴더의 `setup.bat`은 Python과 .NET SDK를 검사하고 없는 도구의 설치를 돕습니다. 설치 시 인터넷과 설치 권한이 필요할 수 있습니다. VS Code 설치는 이 절차와 별도입니다.

#### 기본 구조 — 첫 C# 파일

```csharp
using System;                       // Console이 속한 네임스페이스 사용

// 최상위 문: 별도의 Main을 적지 않고 실행 문장을 작성합니다.
Console.WriteLine("C# 기초편");       // 문자열 출력 후 줄바꿈
Console.WriteLine("실행 성공");        // 문장 끝에는 세미콜론
```

Console은 콘솔 기능을 제공하는 형식, WriteLine은 출력 후 줄을 바꾸는 메서드입니다. 괄호 안에는 출력할 값을 적습니다. 문자열 양쪽은 큰따옴표로 감쌉니다. C#은 대소문자를 구별하므로 Console과 console은 다른 이름입니다.

#### 파일 기반 앱 실행하기

.NET 10에서는 간단한 프로그램을 프로젝트 파일 없이 단일 .cs 파일로 실행할 수 있습니다. VS Code 터미널의 현재 폴더가 파일을 저장한 곳인지 확인하고 실행합니다.

```powershell
dotnet run --file lesson.cs  # 단일 C# 소스 파일을 빌드하고 실행
```

콘솔 프로젝트에서는 Program.cs 전체를 완성 예제로 바꾸어 실행할 수도 있습니다. 기존 Main 안에 using과 클래스 선언까지 붙여 넣지 마세요. 웹 실행기는 임시 콘솔 프로젝트로 코드를 빌드합니다.

#### 웹에서 실행하고 채점하기

1. 이 폴더의 `실습시작.bat`을 실행합니다.
2. 자동으로 열린 `http://127.0.0.1:8767`에서 장을 선택합니다.
3. 아래 실습창에서 코드를 작성합니다.
4. 실행은 입력한 데이터로 한 번, 채점하기는 문제의 테스트 전체로 검사합니다.
5. 종료할 때는 서버 창에서 Ctrl+C를 누릅니다.

HTML을 직접 열면 읽기·편집은 가능하지만 실행에는 Python 서버가 필요합니다. Python이 C# 문법을 해석하는 것은 아닙니다. Python 서버가 .NET SDK를 호출해 실제 코드를 컴파일하고 실행합니다.

### 따라 하기

```csharp
using System;

// 서로 다른 줄에 출력합니다.
Console.WriteLine("C# 기초편");
Console.WriteLine("실행 성공");
```

### 결과 확인

```text
C# 기초편
실행 성공
```

소스 파일에는 명령을 적고, 실행 결과에는 명령이 출력한 문장이 나타납니다.

### 자주 하는 실수

- dotnet을 찾지 못하면 SDK 설치와 새 터미널의 PATH를 확인합니다.
- 저장하지 않으면 이전 코드가 실행될 수 있습니다.
- 컴파일 오류는 첫 오류의 파일명과 줄 번호부터 읽습니다.
- 큰따옴표·괄호·세미콜론을 한 가지씩 확인합니다.
- 코드 블록 바깥의 백틱 세 개는 소스에 붙이지 않습니다.

### 직접 해보기

C# 기초편과 실행 성공을 각각 한 줄에 출력하고 채점하세요. 통과 후 이름을 추가하여 직접 실행해보세요. 추가한 출력은 채점의 정답 형식과 다르다는 점을 구분합니다.

### 힌트와 해설

Console.WriteLine을 두 번 호출합니다. 문자열은 큰따옴표로 감싸고 각 문장 뒤에 세미콜론을 적습니다. 실행되지 않으면 출력 결과 대신 컴파일 오류 메시지를 먼저 확인합니다.
