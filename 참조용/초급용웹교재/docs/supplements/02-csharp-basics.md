# 2장. C# 기초 문법

### 학습 목표

- 자료형, 타입 추론, 상수를 구분합니다.
- 입력을 검증하고 연산 결과를 예측합니다.

### 개념 읽기

#### 기본 구조 — 선언·대입·입출력

다음은 자료형과 변수 이름, 저장할 값이 놓이는 위치를 보여주는 코드입니다. `using`은 사용할 네임스페이스를 지정합니다.

```csharp
using System;

int count = 3;                 // 자료형 변수이름 = 처음 값;
count = 4;                     // 이미 선언한 변수에 새 값 대입
var price = 1200;              // 초기값으로 int 형식 추론
const int MaxCount = 10;       // 다시 대입할 수 없는 상수
string name = "공책";           // 문자열은 큰따옴표
bool isReady = count <= MaxCount; // 비교 결과는 bool
Console.WriteLine($"{name}: {count * price}원"); // 값과 계산 결과 출력

string? input = Console.ReadLine(); // 입력이 끝나면 null일 수 있음
if (int.TryParse(input, out int number)) // 성공 여부와 변환값을 함께 받음
{
    Console.WriteLine(number + 1); // 변환에 성공한 경우에만 사용
}
/* 여러 줄의 설명은
   이 주석 안에 작성합니다. */
```

#### 값을 저장하는 방법 다시 살펴보기

매장 계산기에서 상품 이름은 문자열, 수량은 정수, 할인 여부는 논리값입니다. **자료형**은 값의 종류와 가능한 연산을 정합니다. `int count = 3;`은 정수 변수를 선언하면서 초기화합니다. 이후 `count = 4;`는 기존 변수에 새 값을 대입합니다. 값을 넣기 전에 지역 변수를 읽을 수는 없습니다.

`var count = 3;`도 정수 변수입니다. 컴파일러가 초기값을 보고 형식을 결정하며, 이후 문자열을 대입할 수 없습니다. `var`가 실행 중 자료형을 자유롭게 바꾸게 하는 것은 아닙니다. `const int MaxCount = 10;`은 컴파일 시 결정할 수 있는 상수를 선언하며 다시 대입하지 않습니다.

| 자료형 | 용도 | 주의할 점 |
| --- | --- | --- |
| `int` | 개수와 정수 | 소수를 넣으려면 명시적 변환 등이 필요 |
| `double` | 측정값과 실수 | 십진 소수를 모두 정확히 표현하지 못함 |
| `decimal` | 십진 금액 계산 | 리터럴에 `m` 접미사 사용 |
| `bool` | 참과 거짓 | 문자열 `"true"`와 다름 |
| `string` | 이름과 문장 | 내용이 불변인 참조 형식 |

#### 연산과 입력을 연결하기

`5 / 2`는 정수 나눗셈이어서 2이고 `5 / 2.0`은 2.5입니다. 결과를 `double` 변수에 넣더라도 정수끼리 계산한 뒤라면 잃은 소수 부분이 복구되지 않습니다. `%`는 나머지를 구합니다. `=`는 대입, `==`는 비교입니다. `&&`는 양쪽이 참인지, `||`는 하나 이상이 참인지 검사합니다. 두 연산자는 왼쪽에서 결과가 결정되면 오른쪽을 평가하지 않습니다.

`Console.ReadLine()`은 문자열 또는 입력 끝의 `null`을 반환합니다. `TryParse`의 성공 여부를 확인한 뒤에만 숫자로 사용합니다. 범위 밖 값이나 잘못된 글자를 조용히 0으로 처리하면 사용자가 실수를 알아차리지 못할 수 있습니다.

`//`는 한 줄, `/* */`는 여러 줄 주석입니다. 공개 메서드 설명에는 `///` 문서 주석을 쓸 수 있습니다. 주석에는 코드를 반복하기보다 허용 범위나 판단 이유를 적습니다.

### 따라 하기

```csharp
using System;

const int Quantity = 2;
string name = "공책";
int price = 1200;
var total = price * Quantity;
Console.WriteLine($"{name}: {total}원");
Console.WriteLine(5 / 2);
Console.WriteLine(5 / 2.0 == 2.5);
```

### 결과 확인

```text
공책: 2400원
2
True
```

오른쪽 계산이 먼저 끝난 다음 `total`에 2400이 저장됩니다. 마지막 줄은 실수 계산 결과를 비교합니다.

### 자주 하는 실수

`int n = 2.5;`는 자동으로 소수를 잘라 저장하지 않고 컴파일 오류가 됩니다. `(int)2.5`처럼 변환을 명시하면 0 방향으로 잘라냅니다. 큰 정수의 곱셈은 범위를 넘을 수 있으므로 입력 범위를 정하거나 `long`, `checked`를 검토합니다.

### 힌트와 해설

`int.TryParse`가 성공하고 가격이 범위 안이면 `price * 2`를 출력합니다. 실패 분기에서는 계산하지 않습니다. 상한을 정했으므로 이 문제의 곱셈은 `int` 범위 안입니다.
