# C# 초급용웹교재 · 기초편

폴더 이름은 유지하고 레퍼런스의 **기초 1~8장** 순서와 문서형 탐색 구조로 재구성했습니다. 상단 메뉴, 왼쪽 장 목차, 본문, 오른쪽 페이지 목차를 제공합니다. 각 장 아래에서 Python 서버로 실제 C# 코드를 실행하고 출력 결과를 채점합니다.

## 시작하기

1. 읽기만 할 때는 `index.html`을 엽니다. 인터넷이나 서버가 필요하지 않습니다.
2. 실행·채점은 `실습시작.bat`을 실행하고 `http://127.0.0.1:8767`에서 사용합니다.
3. Windows 10/11, Python 3.10 이상, .NET SDK 10 이상이 필요합니다. 없는 도구는 `setup.bat`으로 설치·검증합니다. 도구 설치에는 인터넷과 권한이 필요할 수 있습니다.
4. ZIP은 폴더 전체를 압축 해제한 다음 사용합니다. 서버 종료는 서버 창에서 Ctrl+C입니다.

명령줄에서는 `python server.py --no-browser`를 사용합니다. 포트 충돌 시 `python server.py --port 8768`을 사용합니다. 읽기·실행에는 Node.js, MkDocs, 외부 Python 패키지나 NuGet 패키지가 필요하지 않습니다. Python 서버가 .NET SDK로 C#을 컴파일하며 Python 자체가 C#을 해석하는 방식은 아닙니다.

VS Code에서도 `dotnet run --file lesson.cs`로 단일 소스 파일을 실행할 수 있습니다. [공식 문서](https://learn.microsoft.com/en-us/dotnet/core/sdk/file-based-apps)를 참고하세요.

## 범위

| 묶음 | 장 |
| --- | --- |
| 시작하기 | 1 개발 환경 구축 · 2 C# 기초 문법 · 3 제어문 |
| 데이터 구조와 컬렉션 | 4 배열 · 5 컬렉션 · 6 문자열 처리 |
| 함수와 메서드 | 7 메서드 기초 · 8 고급 메서드 활용 |

[레퍼런스 기초편](https://rkttu.github.io/csharp-book/part1-basics/)의 장 순서와 탐색 구성을 참고했습니다. 로컬 참조 파일은 `templates/csharp-book-main/docs/part1-basics`입니다. 기초편 1~8장의 본문·세부 절·모든 코드·연습문제와 개요 원문을 빠짐없이 수록했습니다. `docs/part1-basics/*.md`와 `docs/index.md`는 로컬 레퍼런스와 바이트 단위로 같습니다. 화면은 원문 전체 → 별도 추가 학습 → 웹 실습 순서입니다. 주석 포함 기본 구조와 실행 검증 예제는 추가 학습에 보존했습니다. MkDocs 서버 대신 자체 HTML 빌드와 Python 실행 서버를 사용합니다.

심화 9~18장과 실전편은 현재 과정에 포함하지 않습니다. 이전 17단원판은 상위 폴더의 `초급용웹교재-이전17단원.zip`에 보관했습니다.

## 탐색과 기록

왼쪽에서 장을 선택하고 오른쪽에서 절을 선택합니다. 좁은 화면에서는 장 목차 버튼을 사용합니다. 상단 검색은 제목과 본문을 대상으로 장 목차를 필터링합니다. 코드 실습 메뉴나 오른쪽 웹 실습 링크는 편집 내용을 유지하며 현재 장의 실습창으로 이동합니다.

완료 표시·테마·작성 코드는 현재 브라우저에 저장합니다. 기초 8장판은 이전판과 다른 저장 키를 사용하므로 이전 코드가 다른 장에 표시되지 않습니다. 브라우저나 파일 위치가 바뀌면 기록이 유지되지 않을 수 있습니다.

## 실행과 채점

8개 실습에 39개 테스트 입력이 있습니다. 실행은 직접 입력으로 한 번, 채점은 해당 문제의 공개 테스트 전체로 검사합니다. 줄바꿈 방식과 끝의 줄바꿈만 정규화하며 공백·대소문자는 구분합니다. 특정 문법 사용은 출력 채점으로 증명하지 않으므로 코드도 점검하세요. 개발 검증용 정답은 HTML에 포함하지 않습니다.

컴파일 제한 45초, 테스트별 실행 제한 3초, 출력 제한 32KB입니다. 컴파일 오류·오답·실행 중 예외·시간 초과·출력 제한을 구분합니다.

실행기는 학생 본인의 PC에서 본인이 작성한 코드를 실행하는 용도입니다. 코드는 로그인한 사용자 권한으로 실행되며 파일·네트워크를 격리하지 않습니다. 공용 제출 서버로 사용하지 마세요. 서버는 127.0.0.1에 바인딩하고 동일 출처·실행 토큰을 검사합니다. 임시 빌드 폴더는 실행 후 삭제합니다.

## 편집과 생성

- 장 원문 전체: `docs/part1-basics/*.md`
- 주석 포함 기본 구조·완성 예제·해설: `docs/supplements/*.md`
- 개요 원본: `docs/index.md`
- 순서와 묶음: `course.json`
- 화면: `template.html`, `site.css`, `site.js`
- 원문 Markdown 변환: `reference_renderer.py`
- 추가 학습 Markdown 변환: `markdown_renderer.py`
- 실습 원본: `make_exercises.py`
- 실습 편집기: `practice.js`, `practice.css`

HTML 재생성 전 `python -m pip install -r requirements-build.txt`로 빌드 전용 의존성을 설치합니다. 본문 수정 후 `python build.py`를 실행합니다. 원문 동기화 때는 `templates/csharp-book-main/docs/part1-basics`와 해당 파일을 그대로 맞추고 해시를 갱신합니다. 자체 설명은 원문을 덮어쓰지 않고 `docs/supplements`에서 수정합니다. `index.html`과 전체 읽기용 `교재.md`는 생성 결과이므로 직접 수정하지 않습니다. 실습 수정 후에는 `python make_exercises.py`, `python build.py`를 차례로 실행하고 서버를 재시작합니다.

**작성 규칙:** 문법 소개에는 기본 구조의 C# 코드 블록을 반드시 넣고 각 부분의 역할을 주석으로 설명합니다. 기본 구조를 먼저 보여주고 처리 순서와 주의점으로 확장합니다. 기본 구조 블록은 .NET 10의 암시적 using을 기준으로 따로 실행합니다.

## 검증과 배포

`python -m unittest test_reference test_markdown test_course test_runner -v`로 원문 바이트 일치, 절·모든 코드 블록의 웹 표시, Markdown, 8장 대응, 추가 학습의 기본 구조·완성 예제, 실습 정답, 오류·제한·HTTP 처리를 검사합니다. JavaScript 문법 검사에는 Node.js가 필요합니다.

개발용 DOM 동작 검사에는 `npm install --prefix .qa --no-save jsdom@29.1.1`을 한 번 실행합니다. 별도 창에서 Python 서버를 켜고 `node test_site.cjs`를 실행합니다. 장 이동·검색·코드 보관·실제 HTTP 채점을 검사하며 시각적 배치를 검증하는 브라우저 검사는 아닙니다. `.qa`는 배포 ZIP에서 제외합니다.

`python package.py`로 상위 폴더의 `초급용웹교재-배포.zip`을 갱신합니다. `검증결과.json`, `example-checks.json`, `structure-checks.json`은 마지막 검증 결과입니다.

## 원문 보존과 표시 보정

원문: 메모장으로 코딩하는 C# · Jung Hyun, Nam (rkttu). 원문은 AI를 활용해 작성되었습니다. 원본 파일 자체는 수정하지 않았습니다. 표시 단계에서 코드 펜스가 누락·중복된 6곳과 표 안의 OR 연산자 구분 1곳만 보정합니다. 위치와 동작은 `presentation-fixes.json`에 기록합니다. 본문 문장, 코드 내용, 연습문제를 삭제하지 않습니다.

원문의 모든 코드 블록이 독립 실행 예제는 아닙니다. 앞선 변수·클래스·별도 파일이 필요한 조각, 설명용 문법, 컴파일 오류를 보여주는 예시도 그대로 수록했습니다. C# 코드의 **실습창에 넣기**를 누르면 편집기로 복사하여 실행할 수 있습니다. 414개는 수록한 원문 코드 블록의 개수입니다. 채점하기는 각 장의 지정 과제 기준으로 동작합니다. 검증된 별도 과제는 8개, 테스트 입력은 39개입니다.

`reference-checks.json`은 원문별 SHA-256, 전체 절·코드 블록 표시 확인 결과입니다. 이 검사의 원본 대조에는 저장소의 `templates/csharp-book-main`이 필요합니다. 배포 ZIP에는 실행에 필요한 원문과 추가 학습 파일을 모두 포함합니다. 이미 생성된 HTML의 읽기·실행에는 빌드 의존성이 필요하지 않습니다.
