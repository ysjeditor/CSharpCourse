박스(노드)와 화살표(간선)를 직접 적어 본 다음, 그 목록을 AI에게 입력값으로 주어 SVG를 받으세요. 완성한 SVG는 프로젝트의 assets 폴더에 저장하고 README.md에 삽입하세요. 미리보기에서 원본과 흐름을 비교하세요.

3AI에게 줄 입력값을 이 표대로 정하세요

아래 값은 고정값입니다. 그대로 쓰세요 — 값을 바꾸면 기획 문서 03장의 원본 다이어그램과 크기·배치가 어긋납니다.

항목값
형식SVG 코드만 (PNG·JPG 금지)
viewBox0 0 900 540
배경<rect> 하나로 전체 채움, 배경색 #f6f8fc

4아래 프롬프트의 빈칸을 채워서 AI에게 그대로 보내세요

SVG 코드만 출력해 주세요. 설명 문장 없이 <svg>...</svg> 전체를 코드블록 하나로 주세요.

viewBox: 0 0 900 540
배경: #f6f8fc 를 채운 사각형 1개
박스 모양: 둥근 사각형(rx=12) + 왼쪽 4px 색상 바, 세로로 배치
박스 목록(ID · 문구 · 색상):
____(1단계 표를 그대로 옮겨 적기: B1~B5, Exit 6줄)

화살표 목록(출발 → 도착, 조건):
____(2단계 표의 간선 6줄을 그대로 옮겨 적기)

도형 개수: 박스 7개 고정, 화살표 6개 고정
금지: 사진, 그라디언트, 필터
스타일: 깔끔한 플로우차트, 화살표머리는 marker로, 글자는 16px(제목)/13px(라벨)

[힌트: AI가 박스나 화살표 개수를 다르게 그리면 "박스 7개, 화살표 6개로 다시 그려 달라"고 재요청하세요.]

6README에 이미지를 넣고 표시 크기를 조절하세요

  1. VS Code에서 프로젝트 루트의 README.md를 열고, 이미지를 넣을 위치에 커서를 놓으세요.
  2. 탐색기의 assets/flow-loop.svg를 편집 영역으로 드래그한 뒤, Shift 키를 누른 상태로 놓으세요. 생성된 Markdown 이미지 링크의 경로를 확인하세요.
![게임의 턴 진행 흐름](assets/flow-loop.svg)

위 이미지 링크를 아래 <img> 태그로 변경하세요. src에는 생성된 경로, alt에는 그림 설명, width에는 표시할 너비를 넣습니다.

<img src="assets/flow-loop.svg" alt="게임의 턴 진행 흐름" width="480">

README 미리보기(Ctrl+Shift+V)를 열어 이미지가 보이는지 확인하세요. 너무 크거나 작으면 width="400" 또는 width="600"처럼 너비를 조절하세요. 높이는 원본 비율에 맞춰집니다.

SVG의 viewBox는 그대로 유지하고 README의 width로 표시 크기만 조절하세요. 위 경로는 프로젝트 루트의 README.md를 기준으로 합니다. 다른 폴더의 문서에 넣을 때는 드래그로 생성된 상대 경로를 유지하세요.

기획 문서에 이미지를 추가하지 않아도 됩니다. README 미리보기의 그림과 게임기획.html 03장의 원본을 나란히 열어 박스 순서·화살표 방향·조건 라벨을 비교하세요.
