# 설명 — 콘솔 출력

## 구현 파일

[Program.cs](../../src/HelloReadme/Program.cs)의 명시적인 Main에서 인사 문장을 출력합니다.

## 실행

저장소 루트에서 `dotnet run --project ./src/HelloReadme/HelloReadme.csproj -c Release`로 실행합니다. 예상 결과는 `안녕하세요, GitHub!` 한 줄입니다.
