# Quest Log — 모험가 길드

## 01. 어떤 게임을 만드는가

### 한 줄 기획

신규 모험가가 이름을 등록하고 사냥으로 성장하여 전직하고 길드에 가입하는 **콘솔 기반 텍스트 RPG**입니다. 화면 장식보다 입력 → 판단 → 상태 변경 → 결과 안내의 연결을 구현하는 것이 학습 목표입니다.

<!-- SVG:journey -->

### 플레이어가 할 수 있는 일

이름 등록, 사냥, 전직, 길드 가입 신청, 몬스터 도감 확인, 길드원 검색·추방, 내 정보 확인, 종료를 제공합니다. 메뉴 번호가 잘못되면 안내 후 메뉴로 돌아갑니다. 기본 게임에는 저장·불러오기, 방어력, 골드, 아이템, 장비, 스킬 메뉴가 없습니다.

**완성 기준:** 메뉴 하나만 동작하는 것이 아니라 사냥으로 변경된 상태가 전직·가입·내 정보·도감에 연결되어야 합니다.

## 02. 플레이 화면과 입력 흐름

### 시작 화면에서 메뉴로

<!-- SVG:screens -->

이름은 앞뒤 공백을 제거합니다. 비어 있거나 공백뿐이면 **이름없는떠돌이**로 시작합니다. 새 캐릭터는 모험가, 레벨 1, HP 100/100, 공격력 15, 처치 수 0입니다. 시작할 때 기존 길드원 세라와 도윤이 등록됩니다. 플레이어는 아직 가입하지 않은 상태입니다.

### 메뉴 규칙

| 입력 | 기능 | 처리 후 이동 |
| --- | --- | --- |
| 1 | 몬스터 선택과 사냥 | 승패 처리 후 메인 메뉴 |
| 2 | 기사·도적·마법사 전직 신청 | 성공·실패 안내 후 메뉴 |
| 3 | 길드 가입 신청 | 중복·조건 확인 후 메뉴 |
| 4 | 몬스터 도감 | 표시 후 메뉴 |
| 5 | 길드 명단, a: 검색, b: 추방 | 한 작업 후 메인 메뉴 |
| 6 | 내 정보 | 표시 후 메뉴 |
| 0 | 종료 | 종료 메시지 후 끝 |

입력 앞뒤 공백은 정리합니다. 관리 메뉴에서 a/b 외 입력은 뒤로 가기입니다. 메인 메뉴의 입력 종료(EOF)는 안전 종료로 처리합니다. 최종 게임 시작 화면의 환영 문장은 가입 완료와 같지 않습니다.

## 03. 전투 한 턴의 규칙

<!-- SVG:battle -->

### 공격과 승패

모험가가 먼저 공격합니다. 몬스터가 쓰러지면 반격하지 않습니다. 살아 있다면 정해진 공격력으로 반격합니다. 둘 중 한쪽의 HP가 0이 될 때까지 반복하며 HP는 0 아래로 내려가지 않습니다.

모험가 공격은 **30% 확률로 치명타**입니다. 일반 피해는 공격력 그대로, 치명타 피해는 공격력 × 1.5의 소수 부분을 버린 정수입니다. 공격력이 15이면 일반 15, 치명타 22입니다. 몬스터는 치명타를 사용하지 않습니다.

### 전투 종료 후

- 승리: 해당 종을 도감에 처치로 표시하고, 처치 수와 성장 처리를 적용합니다.
- 패배: 처치·성장 보상을 지급하지 않고 모험가 HP를 최대치로 회복한 뒤 메뉴로 돌아갑니다.
- 전투 중 도주·회복·대상 변경 선택은 기본 기능에 없습니다.

난수 때문에 실제 턴 수는 달라집니다. 검증할 때는 일반/치명타를 분리해 확인하거나 최소·최대 피해 범위를 기준으로 판단합니다. 기획에서 특정 턴 수를 항상 보장하지 않습니다.

## 04. 성장과 전직 조건

<!-- SVG:growth -->

### 성장은 누적 경험치 막대가 아닙니다

승리할 때 처치 수가 1 증가합니다. 그 몬스터 보상이 30 이상이거나, 증가한 처치 수가 짝수이면 레벨이 **한 번** 오릅니다. 두 조건을 동시에 만족해도 두 번 오르지 않습니다. 보상을 합산하는 경험치 저장소는 없습니다.

레벨 상승마다 최대 HP +10, 공격력 +3, HP 완전 회복입니다. 슬라임만 잡으면 처치 2회에서 레벨 2, 처치 4회에서 레벨 3이 됩니다. 고블린 이상은 보상이 30 이상이라 처치마다 레벨이 오릅니다.

### 전직 조건과 보너스

| 지망 직업 | 공통 조건 | 추가 조건 |
| --- | --- | --- |
| 기사 | 현재 모험가이며 레벨 3 이상 | 처치 수 4 이상 |
| 도적 | 현재 모험가이며 레벨 3 이상 | 처치 수 3 이상 |
| 마법사 | 현재 모험가이며 레벨 3 이상 | 레벨 4 이상 |

성공하면 직업 변경, 최대 HP +20, 공격력 +5, HP 완전 회복을 적용합니다. 전직한 캐릭터는 재전직할 수 없습니다. 실패하면 상태를 변경하지 않고 부족한 조건을 안내합니다. 직업별 추가 전투 스킬은 없습니다.

## 05. 몬스터 도감과 전투 대상

<!-- SVG:monsters -->

### 도감은 기록이며 사냥은 새로운 만남입니다

번호는 1부터 보여주고, 입력은 1~4만 허용합니다. 숫자가 아니거나 범위를 벗어나면 전투를 시작하지 않습니다. 같은 종을 다시 선택하면 항상 최대 HP의 **새 전투 대상**이 등장합니다. 이전 사냥의 남은 HP를 다음 사냥으로 가져오지 않습니다.

도감은 네 종을 고정 순서로 표시하고 각 종의 처치 여부를 보여줍니다. 같은 종을 여러 번 처치해도 도감에는 하나의 처치 표시만 필요합니다. 도감 완성 보상은 확장 과제이며 기본 기능이 아닙니다.

## 06. 길드 가입·명단·검색·추방

<!-- SVG:guild -->

### 가입과 관리의 규칙

플레이어 가입에는 **레벨 2 이상 AND 처치 수 1 이상**이 필요합니다. 하나만 충족하면 거절하고 부족한 레벨과 처치 수를 0 이상 숫자로 안내합니다. 동일한 이름이 이미 등록되어 있으면 중복 가입으로 안내합니다. 이름 비교는 기본 문자열 비교이며 대소문자를 자동으로 통합하지 않습니다.

명단은 등록 순서를 유지합니다. 검색은 정확한 이름으로 한 명을 찾고, 없으면 없다고 안내합니다. 추방 성공 후 명단과 검색 결과 모두에서 사라져야 합니다. 없는 사람을 추방하려고 하면 실패 안내를 표시합니다.

### 함께 쓰는 상태

플레이어가 가입한 뒤 성장하면 명단과 검색에서도 현재 상태를 보아야 합니다. 가입 순간의 복사본으로 고정하는 기능은 아닙니다. 플레이어 자신을 추방하는 것도 현재 코드에서는 허용하며, 이후 조건을 만족하면 다시 가입 신청할 수 있습니다. 별도의 관리자 권한·강퇴 사유는 없습니다.

## 07. 열 개의 작은 기능을 게임으로 연결하기

<!-- SVG:learning -->

| 번호 | 작은 기능 | 완성 게임에서의 역할 |
| --- | --- | --- |
| 1 | 이름 입력과 증명서 | 시작 화면과 캐릭터 생성 |
| 2 | 두 캐릭터 HP 교환 | 기본 메뉴 미연결. 확장 연습용 기능 |
| 3 | 가입 조건 판단 | 플레이어의 가입 허용 여부 |
| 4 | 조건에 따른 전직 | 직업 선택과 상태 변경 |
| 5 | 끝날 때까지 반복 | 메인 메뉴와 전투 |
| 6 | 치명타 계산 | 모험가의 공격 피해 |
| 7 | 값과 동작 묶기 | 캐릭터·몬스터의 상태 관리 |
| 8 | 고정 목록 순회 | 몬스터 도감 |
| 9 | 목록에서 제거 | 길드원 추방 |
| 10 | 이름으로 검색 | 길드원 조회 |

체력 교환은 현재 메뉴에서 사용 가능한 스킬이 아닙니다. 기능이 준비되어 있는 것과 플레이 흐름에 연결된 것은 구별합니다. 확장하려면 대상 종류와 HP 상한 정책부터 새로 정해야 합니다.

## 08. 데모와 통합본의 차이

### 이번 실습의 기준은 통합 게임입니다

| 항목 | 개별 문법 데모 | 통합 게임 기준 |
| --- | --- | --- |
| 가입 | 레벨 5, 처치 3 | 레벨 2, 처치 1 |
| 전직 | 레벨 10과 힘·민첩·지능 | 레벨·처치 수, 현재 직업 |
| 시작 환영 | 길드 일원이라는 문구 | 캐릭터 생성 후 별도 가입 신청 |
| 몬스터 | 일부 HP·공격력 값이 다름 | 05단원의 네 종 수치 |
| 명단 | 문자열 목록과 조건 삭제 | 캐릭터 목록과 정확한 이름 추방 |
| 검색 | 이름 → 직업·레벨 튜플 | 이름 → 같은 캐릭터 객체 |

개별 데모는 해당 문법을 작게 보여주고, 통합본은 여러 기능을 함께 플레이하도록 수치를 조정한 것입니다. 데모의 숫자를 그대로 옮기면 문법이 맞아도 이번 기획과 다른 프로그램이 됩니다.

### 완료 판정

빈 이름의 기본값, 잘못된 메뉴, 조건 미달 가입, 두 번째 슬라임 처치 후 가입, 네 번째 슬라임 처치 후 기사 전직, 같은 이름 중복 가입, 기존 길드원 검색·추방, 반복 사냥의 새 HP, 패배 후 회복, 종료를 확인합니다. 코드의 파일 수가 맞는 것만으로 완성이라고 판단하지 않습니다.
