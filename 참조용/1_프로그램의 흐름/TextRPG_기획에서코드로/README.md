# TextRPG — 기획에서 코드로

`index.html`을 더블 클릭합니다. 서버와 설치 없이 기획 문서·시스템 문서를 나란히 읽고 실습 과제를 선택할 수 있습니다. HTML 세 개를 같은 폴더에 두세요. 개별 문서의 SVG·스타일·본문·원본 코드는 각 HTML에 내장되어 있습니다.

## 제공 문서

| 문서 | 무엇을 읽는가 |
| --- | --- |
| `기획문서.html` | 플레이어 관점의 화면, 규칙, 상태 변화, 완료 기준. 8개 단원 |
| `시스템문서.html` | 실제 클래스·멤버·객체·호출·자료구조와 구현 순서. 9개 단원 |
| `index.html` | 두 문서 보기, 10개 구현 과제, 직접 확인 체크리스트 |
| `기획문서.md`, `시스템문서.md` | 수정 가능한 본문 원본 |
| `assets/*.svg` | 개별 활용 가능한 SVG 도식 13개 |
| `실습가이드.md` | 프로젝트 생성과 점진적 조립 순서 |

## 대상 코드와 문서 기준

`templates/TextRPG/src`의 10개 데모와 `templates/TextRPG/src/projects/text-rpg` 통합 프로젝트를 확인했습니다. 요청의 `Projects/test-rpg`는 별도 경로가 없어 실제 통합 프로젝트를 기준으로 사용했습니다.

기획 수치와 시스템 계약은 **통합본** 기준입니다. 개별 데모와 다른 가입·전직·몬스터 수치는 기획 문서 08단원에 비교했습니다. HP 교환은 메서드만 있고 기본 메뉴에는 연결되지 않았습니다. 시스템 문서의 원본 코드 펼치기는 생성 시점의 파일이며 해시는 `source-manifest.json`에 기록됩니다.

## 실습 환경

읽기에는 Python과 .NET이 필요하지 않습니다. 실제 구현은 .NET 10 SDK가 설치된 PC에서 별도의 콘솔 프로젝트로 진행합니다. .NET 10을 지원하는 Visual Studio나 dotnet CLI를 사용할 수 있습니다. 웹 화면은 코드 실행기나 자동 채점기가 아니며, 완료 표시는 학생 본인의 확인 기록입니다.

## 유지관리

`python build.py`로 HTML·SVG·소스 스냅샷을 갱신합니다. 기존 입문웹교재의 변환 함수와 스타일을 재사용하며 재생성 시 해당 폴더와 원본 TextRPG 프로젝트가 필요합니다. `python 검증.py`는 SVG 파싱·소스 해시·문서 링크·JavaScript와 실제 C# 규칙을 검증합니다. 검증 시 Python·Node.js·.NET 10 SDK가 필요합니다.

이 문서는 소스의 현재 동작을 설명하며, 원본 게임 코드를 변경하지 않습니다. 특히 Join의 자격 검사 생략, 음수 피해·HP 교환 상한 미검증 등은 현재 계약의 경계로 표시했습니다.
