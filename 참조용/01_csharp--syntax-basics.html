문제

HP 바가 줄지 않는다?

최대 체력 120인 캐릭터의 HP 바를 그리려고 퍼센트를 계산했습니다. 수학으로는 맞는 식인데, 맞을 때마다 바가 0%로 뚝 떨어집니다.


            int hp = 75, maxHp = 120;
            // 기대: 62, 실제: 0
            int percent = hp / maxHp * 100;
컴퓨터는 눈치가 없다

C#에서 int ÷ int는 정수입니다. 75 / 120은 0.625가 아니라 0이고, 0에 100을 곱해도 0입니다. 문법을 안다는 건 코드가 글자 그대로 무엇을 하는지 아는 것입니다.

프로그램 구조

문, 세미콜론, 블록, 주석


              // Program.cs — 최상위 문(top-level statements)
              using System;               // 다른 곳에 있는 기능을 가져온다

              int hp = 100;               // 문(statement)은 ;로 끝난다
              int damage = 30;
              if (damage > 0)
              {                           // { } 블록: 여러 문을 하나로
                  hp -= damage;
                  Console.WriteLine($"HP: {hp}");   // HP: 70
              }
              /* 여러 줄 주석은 이렇게 감싼다 */
            

              namespace MyGame;  // 이름 공간
              public static class Program
              {
                  public static void Main()  // 시작점
                  {
                      Console.WriteLine("Hello");
                  }
              }
  1. using — Console은 System 이름 공간(namespace)에 있습니다. using으로 가져오면 System.Console을 줄여 쓸 수 있습니다.
  2. 문(statement) — 컴퓨터에게 내리는 명령 하나. 끝에 ;를 붙이고, 위에서 아래로 순서대로 실행됩니다.
  3. 블록(block) — { }는 여러 문을 한 덩어리로 묶습니다. 블록 안에서 만든 변수는 블록 밖에서 보이지 않습니다.
  4. 주석(comment) — //부터 줄 끝까지, 또는 /* */ 사이는 컴파일러가 무시하는 메모입니다.
  5. Main — 전통적인 프로그램 시작점. 최상위 문은 컴파일러가 이 Main을 대신 만들어 주는 C# 9 문법입니다. Unity 스크립트에는 Main이 없고 엔진이 메서드를 불러 줍니다.

핵심 아이디어

변수는 크기가 정해진 상자

변수(variable)는 이름 붙은 저장 공간이고, 타입(type)이 그 크기를 정합니다. int는 32비트라 약 ±21억까지만 담습니다. 넘치면 오류 없이 반대쪽 끝으로 감깁니다(wraparound).

score += 10score = score + 10 의 줄임 (-= *= /=도 같음)
score++1 증가 (score--는 1 감소)

타입과 리터럴

값마다 맞는 상자가 있다

타입크기담는 값리터럴 예
int4바이트정수 −2,147,483,648 ~ 2,147,483,647100
long8바이트정수 약 ±9.2×1018100L
float4바이트실수, 유효 숫자 약 7자리5.5f
double8바이트실수, 유효 숫자 약 15~16자리5.5
bool1바이트true / falsetrue
char2바이트문자 하나 (UTF-16)'A'
string가변문자열 (글자 수만큼)"Hero"
 

              float speed = 5.5f;        // f가 없으면 double → 오류
              double gravity = 9.81;     // 소수 리터럴의 기본은 double
              var name = "Knight";       // 오른쪽 값을 보고 string으로 추론
              const int MaxHp = 100;     // 절대 바뀌지 않는 상수
              char grade = 'A';          // 문자 하나: 작은따옴표
              bool isAlive = true;
              long gold = 3_000_000_000L; // _는 자릿수 구분용
              int hp = MaxHp;
              string msg = $"{name} HP {hp}/{MaxHp}, {speed:F1} m/s";
              Console.WriteLine(msg);    // Knight HP 100/100, 5.5 m/s
float speed = 5.5;는 컴파일 오류

소수점 리터럴은 기본이 double(8바이트)입니다. 4바이트 float에 넣으면 정밀도가 깎이므로 컴파일러가 막습니다(CS0664). 5.5f처럼 f를 붙이세요. 게임 엔진은 대부분 float를 씁니다.

var와 const

var는 타입을 생략할 뿐, 타입이 없는 게 아닙니다. 한 번 string이면 끝까지 string입니다. const는 컴파일할 때 값이 정해지고 다시 대입할 수 없습니다.

문자열 보간 $"..."

앞에 $를 붙이면 { } 안의 식이 값으로 바뀝니다. {speed:F1}은 소수 한 자리로 표시하라는 서식입니다.

연산자 · 형변환

나눗셈과 형변환 실험실

정수끼리 나누면 소수부를 0 쪽으로 버립니다. 한쪽만 float여도 실수 나눗셈이 됩니다. %는 나머지이고, 부호는 왼쪽 수를 따릅니다.

int → float는 정보가 사라지지 않아 암시적으로 바뀌지만, float → int는 소수부가 사라지므로 (int)로 명시적 형변환(cast)을 써야 합니다.

조건문

처음 참인 분기 하나만

else if 사슬은 위에서부터 검사하다 처음 true인 블록 하나만 실행하고 나머지는 보지도 않습니다. 조건의 순서가 곧 의미입니다.


            string state;
            if (hp <= 0)
                state = "사망";
            else if (hp < 30)
                state = "위험";
            else if (hp < 70)
                state = "부상";
            else
                state = "건강";
          

            string state;
            if (hp <= 0)
                state = "사망";
            else if (hp < 70)      // 30 미만도 여기서 걸린다
                state = "부상";
            else if (hp < 30)      // 도달할 수 없는 분기
                state = "위험";
            else
                state = "건강";
          

            // switch 식 (C# 9): 위에서부터 첫 패턴 하나
            string state = hp switch
            {
                <= 0 => "사망",
                < 30 => "위험",
                < 70 => "부상",
                _ => "건강",          // _ : 나머지 전부
            };
연산자뜻 (결과는 모두 bool)
== !=같다 / 다르다 (대입 =와 다름)
< <= > >=크기 비교
&& || !그리고 / 또는 / 아니다
단락 평가 (short-circuit)

&&는 왼쪽이 false면, ||는 왼쪽이 true면 오른쪽을 실행하지 않습니다. i < a.Length && a[i] > 0은 범위 밖을 읽지 않습니다.

반복문

반복문 한 줄씩 따라가기

여러 값 담기

배열, List<T>, 그리고 null


            int[] scores = { 90, 75, 60 };       // 길이 3, 고정
            scores[0] = 95;                      // 인덱스는 0부터
            Console.WriteLine(scores.Length);    // 3
            // scores[3] = 1;  → IndexOutOfRangeException

            var inventory = new List<string>();  // 크기가 늘어나는 목록
            inventory.Add("Potion");
            inventory.Add("Sword");
            inventory.Remove("Potion");
            Console.WriteLine(inventory.Count);  // 1

            string? target = null;               // 아직 대상이 없음
            int? bestTime = null;                // 기록이 없을 수도 있는 int
            if (bestTime.HasValue)
                Console.WriteLine(bestTime.Value);
            Console.WriteLine(target?.Length ?? 0);  // 0

배열 (array)

같은 타입 값을 정해진 개수만큼 나란히 담습니다. 칸 번호는 0부터 Length - 1까지. new int[5]로 만들면 모든 칸이 0입니다.

List<T>

T 자리에 담을 타입을 적습니다. Add/Remove로 개수가 바뀌는 인벤토리·적 목록에 씁니다. 개수는 Length가 아니라 Count. (System.Collections.Generic)

null과 int?

null은 “아무것도 가리키지 않음”. int?는 값이 없을 수도 있는 int입니다. ?.은 null이면 멈추고, ??는 null일 때 쓸 기본값입니다.

배열과 리스트의 내부 동작은 배열과 리스트에서 자세히 다룹니다.

주의

초보 게임 코드에서 자주 터지는 곳

if (hp = 0)

=는 대입, 비교는 ==. C#은 int를 bool로 바꾸지 않아 컴파일 오류(CS0029)로 막아 줍니다. C/C++에선 조용한 버그입니다.

i <= arr.Length

마지막 인덱스는 Length - 1. <=로 돌면 마지막 회차에 IndexOutOfRangeException. <나 foreach를 쓰세요.

실수를 ==로 비교

0.1f를 10번 더하면 1.0000001이라 == 1f는 false. MathF.Abs(a - b) < 0.0001f처럼 오차를 허용하세요.

Math.Round(2.5)는 2

기본 반올림은 .5에서 짝수 쪽(은행가 반올림). 학교식은 MidpointRounding.AwayFromZero를 넘깁니다.

case 뒤 break 빠뜨림

문장이 있는 case는 break(또는 return)로 끝나야 합니다. 다음 case로 흘러내리기는 금지(CS0163).

b = b + 1; (byte)

byte + int는 int라 형변환 없이 못 넣습니다(CS0266). b++, b += 1은 되지만 255 다음은 0.


              switch (weapon)       // 값 하나로 여러 갈래
              {
                  case "sword":
                      damage = 10;
                      break;        // 빠뜨리면 CS0163
                  case "bow":
                  case "crossbow":  // 빈 case는 묶을 수 있다
                      damage = 7;
                      break;
                  default:          // 어느 case도 아니면
                      damage = 1;
                      break;
              }

값 하나를 여러 상수와 비교할 때는 switch 문이 else if 사슬보다 읽기 쉽습니다. 범위·조건으로 고를 때는 앞 장의 switch 식이 간결합니다.

확인 문제

이해했는지 확인해 볼까요?

Q1. int a = 7, b = 2; float c = a / b; 이후 c의 값은?

3.5를 원하면 (float)a / b처럼 계산 전에 한쪽을 실수로 바꿔야 합니다.

Q2. int n = (int)-2.7f; 의 결과는?

음수에서 “버림”과 “내림”은 다릅니다: (int)-2.7f == -2, MathF.Floor(-2.7f) == -3.

Q3. 아래 코드가 끝난 뒤 count의 값은?


            int count = 0;
            for (int i = 0; i < 5; i++)
            {
                if (i == 1) continue;
                if (i == 3) break;
                count++;
            }

continue = 이번 회차만 건너뛰고 증가식으로, break = 반복문을 즉시 탈출.

정리

C# 문법 기초 한눈에 보기

  • 문은 ;로 끝나고 위에서 아래로 실행되며, { } 블록으로 묶입니다.
  • 타입이 상자의 크기와 범위를 정합니다. int는 넘치면 조용히 감깁니다.
  • 소수 리터럴은 double — float에는 f를 붙입니다.
  • int / int는 정수, (int)는 0 쪽으로 버림, 반올림은 Math.Round.
  • else if와 switch 식은 처음 맞는 분기 하나만 실행합니다.
  • continue는 회차 건너뛰기, break는 탈출, do-while은 최소 1회.
  • 배열은 길이 고정·0부터, List<T>는 늘어나는 목록, int?는 값이 없을 수 있음.
