## 매일 하는 일 (리듬)

1. 작업 브랜치를 만들고 코드·문서를 작성합니다.
2. [개발 일지](./docs/개발일지.md)에 오늘 한 덩어리를 추가하고, **어떤 문서를 썼는지** 고릅니다([규격](./docs/규격/README.md) 참고).
3. `add → commit → push → PR` 로 올리고 내 diff에 셀프 코멘트를 남깁니다.
4. 위 **개발 기록** 표에 오늘 한 줄을 추가합니다.

cd src
dotnet run -c Release
