# 규격: 어려웠던 점

막혔던 문제를 하나씩 정리합니다. 같은 문제를 겪을 사람이 **재현**할 수 있게 쓰세요.

## 언제 쓰나

- 버그·막힘을 겪고 해결했을 때. 원인과 해결을 다음의 나에게 남깁니다.

## 형식 (문제마다 한 덩어리)

```markdown
## [문제 제목]
- 증상: ____              [힌트: 어떤 입력에서 무엇이 기대와 다른가]
- 원인: ____              [힌트: 브레이크포인트·로그로 확인한 실제 원인]
- 해결: ____              [힌트: 무엇을 바꾸니 됐는가]
- 재발 방지: ____          [힌트: 추가한 테스트나 규칙]
```
