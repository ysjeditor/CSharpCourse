# 규격: TIL (개념 정리형)

새 개념을 이해한 날 쓰는 문서입니다. 들은 것을 **내 말로 다시 구성**해 기록합니다.

## 언제 쓰나

- 쓸 코드가 아직 없는 **개념·원리** 강의를 들었을 때.

## 형식 (이 뼈대로 쓰세요)

```markdown
# 오늘 이해한 것: ____        [힌트: 명사 말고 "~가 어떻게 ___ 되는가"로]
- 한 문장 요약: ____
- 핵심 흐름(순서·구성): ____   [힌트: 단계나 구성 요소를 순서대로]
- 내 말로 설명: ____          [힌트: 핵심 개념 2~3개, 강의 문장 복붙 금지]
- 한 줄 교훈 / 더 궁금한 점: ____
```

## 좋은 TIL의 기준

- ⓐ 핵심 구조를 **순서대로 복원**했는가
- ⓑ 개념을 **자기 말로** 다시 썼는가(복붙 아님)
- ⓒ 그림 없이 글만 읽어도 **남이 이해**하는가

> 완성 예시: [TIL-개념정리/](../TIL-개념정리/) 폴더의 학생·강사 샘플을 참고하세요.
