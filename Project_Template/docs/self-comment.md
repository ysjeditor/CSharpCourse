# 셀프 코멘트

PR을 열면 **내 PR의 변경된 줄**에 셀프 코멘트를 남기세요. `[nit|question|blocker]`로 분류하고 근거를 붙이세요.

- nit은 취향, question은 의도 확인, blocker는 고치기 전엔 병합하지 않음입니다.
- GitHub PR에 코멘트를 남긴 뒤, 아래에 PR별로 요약하세요. 전체 PR 목록은 [PR 작업 내역](./pr-log.md)에 있습니다.

## PR #N 셀프 리뷰

```markdown
[nit]      (파일:줄) ____  — 취향 수준: ____
[question] (파일:줄) ____  — 이렇게 하면 ____ 상황에서 ____ 될 것 같은데, 의도가 있나요?
[blocker]  (파일:줄) ____  — 병합 전 꼭: ____   근거: ____
```

- 반영 결과: ____            [힌트: 고친 커밋 또는 "그대로 둔 이유"]

## 회고

- 다음에 바꿀 점: ____
