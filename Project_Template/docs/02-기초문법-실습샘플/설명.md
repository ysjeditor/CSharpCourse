# 설명 — [완성 샘플: C# 기초문법 실습]

> README의 주제를 뒷받침하는 기술 문서입니다. 구현 내용을 설명합니다.
> 소재: `csharp-book` 2장(기초 문법)의 예제를 File-based App `.cs`로 재현.

## 무엇을 만들었나요

- C# 기초 문법(변수·타입·연산자·콘솔 입출력)을 확인하는 작은 콘솔 예제 묶음과, 2장 실습 3문제(개인정보 입출력·사칙연산 계산기·성인 판별)를 각각 실행 가능한 `.cs`로 작성했습니다.

## 구조 (폴더·파일 책임)

- `src/01-basics/02a-변수와타입.cs` — `int·string·bool·double`, `var` 타입 추론, `const` 상수 선언·출력.
- `src/01-basics/02b-연산자.cs` — 산술(`+ - * / %`)·비교(`== != > <`)·논리(`&& || !`)·대입(`+= …`), 정수/실수 나눗셈 차이.
- `src/01-basics/02c-콘솔입출력.cs` — `WriteLine`/`Write`, `ReadLine`, 문자열 보간·서식(`:F2`, `:C`).
- `src/01-basics/02-실습1-개인정보.cs` / `02-실습2-계산기.cs` / `02-실습3-성인판별.cs` — 2장 실습 문제.

> File-based App이라 파일 하나가 독립 실행됩니다. `.sln`·`.csproj` 없이 파일 단위로 돌립니다.

## 규칙 → 코드 → 검증

| 규칙 | 구현(파일) | 검증(입력 → 기대 출력) |
|---|---|---|
| 두 정수의 `/`는 몫만 남는다 | `02b-연산자.cs` | `10 / 3` → `3`, `10.0 / 3` → `3.333…` |
| `ReadLine`은 string이라 변환이 필요하다 | `02-실습2-계산기.cs` | `"12"` → `double.Parse` → `12` 로 연산 |
| 숫자가 아닌 입력은 멈추지 않고 되묻는다 | `02-실습1-개인정보.cs` | `"abc"` → `TryParse` 실패 → 안내 출력 |
| 성인 여부는 `age >= 18`의 bool 결과 | `02-실습3-성인판별.cs` | `18` → `True`/"성인", `17` → `False`/"미성년자" |

## 실행·검증 결과

- 실행 방법: `dotnet run src/01-basics/02b-연산자.cs` (파일명만 바꿔 각 예제 실행).
- 확인 결과: 6개 `.cs` 모두 빌드·실행 성공. 위 표의 입력 4종에서 기대 출력과 일치함.
