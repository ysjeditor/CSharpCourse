## 무엇을
- 객체지향 프로그래밍
- 추상 클래스
- 인터페이스 vs 상속
- A is B -> 상속
- A can B -> 인터페이스
- 자료구조 알고리즘 -> 빅오표기법, 다양한 자료구조 들이 있고,
효율적인 방법을 찾아서 사용하고 있었다.
- 배열 : 메모리 주소상에서 값을 넣을 때 공간을 할당하며 추후 값을 넣을 때는 공간을 추가할당하지 않는다.
- 연결리스트 : 원소들이 다음 주소를 가리킨다.
- 스택 : 나중에 들어온 함수를 먼저 처리한다.
- 큐 : 미리 들어온 것을 먼저 처리한다.
- HashTable : 우편아저씨가 집 현관입구에 있는 곳에 우편을 넣어놓는다. 이 우편이 집 주소를 가리킨다.
