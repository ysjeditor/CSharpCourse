🚀 우주 슈팅 게임 (OOP 설계 적용판)

설계 시트의 공통 부모(Entity), 갈래(Enemy), 값 변형, 인터페이스(IDamageable, IShooter, IPickup) 구조를 그대로 구현했습니다.

HP: 100 무기 Lv: 1 점수: 0

우주 슈팅 디펜스

방향키 / WASD : 기체 이동
Space : 레이저 발사 (자동 연사 가능)
운석은 피하고, 적기와 포탑을 격추하며 파워업을 획득하세요!

📐 적용된 클래스 & 인터페이스 구조

🚀 플레이어 기체 (Entity)
IDamageable IShooter
👾 소형 / 중형 적기 (Enemy)
값만 다름 IDamageable IShooter
🗼 레이저 포탑 (Enemy 자식)
IDamageable IShooter
☄️ 운석 (Entity)
IDamageable
⚡ 파워업 (Entity)
IPickup
abstract class Entity { update(); render(); } class Enemy extends Entity { /* IDamageable, IShooter */ } class LaserTurret extends Enemy { /* 조준 사격 행동 */ } class PlayerShip extends Entity { /* IDamageable, IShooter */ } class Meteor extends Entity { /* IDamageable (사격 불가) */ } class PowerUp extends Entity { /* IPickup (피격 불가) */ } // 값만 다름: new Enemy({ hp: 20, speed: 3 }) vs ({ hp: 60, speed: 1.5 })
💡 설계 포인트 확인하기
• 운석은 사격하지 않고 체력만 가집니다(IDamageable).
• 파워업은 총알에 맞지 않고 플레이어가 닿아야 획득됩니다(IPickup).
• 소형/중형 적기는 같은 Enemy 클래스에 숫자 값만 다릅니다.
• 레이저 포탑은 Enemy를 상속받아 플레이어를 향해 조준 사격합니다.
