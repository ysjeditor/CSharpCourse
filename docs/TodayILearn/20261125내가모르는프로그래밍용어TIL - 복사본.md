# 입문용웹교재07
- double 이란 무엇인가? 몇 바이트인가? : 8바이트(64bit)이며 float보다 정확도가 2배 더 높아서 double이라고 한다.
- 필드란 무엇인가? Player라는 class가 있다고 했을때 C#으로 예를 들어라고 하면 설명못하겠다.
-> class안의 멤버 변수만 포함한다.

필드 코드 예시 :
```
class Player
{
    int hp; //int hp 라는 필드
    int mp; //int mp 라는 필드
}
```

# 느낀점
그렇다면 float은 어떨때 사용해야하고 double은 어떨때 사용해야하지? float은 몇 바이트지?
-> 바로 학습한 결과로 float은 4바이트(32bit)이며 정밀한 수학적 계산이나 금융쪽에서는 double을 쓰지만
유니티에서는 거의 float으로 구현했기때문에 게임에서는 flaot을 많이쓰며 4바이트 차이가 성능에 영향을 주지 않기 때문에
계산이 정확해야 하는 곳에서는 double을 쓴다.
float은 6~7자리 까지 정확도가 있음
