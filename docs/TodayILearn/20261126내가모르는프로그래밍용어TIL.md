# 입문용웹교재08
- 범위(Scope) : 변수 이름을 사용할 수 있는 영역

범위 코드 예시 :
```
class Player
{
    int a = 1;
    int b = 2;

    public void Print()
    {
        int c = a+b;
        return c;
    }
}
```
- 여기서 int a와 b의 범위는 class 내부이며 함수 안 중괄호에서도 사용할 수 있다.

# 느낀점
- 이 범위를 제대로 활용해서 함수를 구성해야겠다. 그리고 Class의 필드와 범위가 미묘하지만 다르다
- Class의 필드는 클래스 내부에 지정된 멤버 변수들이고
- 범위는 그보다 더 확장개념인 변수를 '사용'할 수 있는 영역이다.
