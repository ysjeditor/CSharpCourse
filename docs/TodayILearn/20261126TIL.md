## 📖 배운 내용
### 1. return값에 지역변수를 넣으면 출력되지않는다.
- 지역 변수의 사용지점을 확인했다.

```csharp
static bool Output(int input)
{
    bool result = false;
    if (input >= 60)
    {
        result = true;
    }
    return result;
}
```
- 함수 지역변수 안에 bool형인 result를 선언하고 초기화했으며 if문을 통해 인자로 받은 값이 60 이상이라면 result를 true로 초기화했다.
- 하지만 return에서는 result값을 불러오지 못했다.

```csharp
static bool Output(int input)
{
    return input >= 60;
}
```
- 해당 문제를 다음과 같이 해결했다.
- 해결된 이유를 공부해보니 if 문 안에서 함수 범위에 있는 result를 끌어다가 if문 내부에서 값을 초기화는 했지만 if문이 종료되면서 result의 값이 없어져서였다.
- 그래서 아예 메서드 본문 안에서 조건을 검사하고 참이면 true가 출력되게 하였다.

## 💡 느낀 점
- 함수를 구성할 때 함수 내부에 중괄호가 있으면 거기서 실행된 변수는 사라지는구나를 알게 되었다.
- 항상 함수를 만들면 컴파일 오류가 떠서 하나 구현하는데 오래걸렸는데 이제부터는 함수를 만들면 이 점을 기억해서 빠르고 정확하게 만들어보아야 겠다.
