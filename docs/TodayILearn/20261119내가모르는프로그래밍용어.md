# 입문용 웹교재
자료형 또는 데이터 형식(Type) : 변수에 어떤 종류의 값을 저장할지

선언(Declaration) : 변수를 처음 만드는 일

초기화(Initialization) : 선언할 때 첫 값을 지정하는 것
ex) 체력을 100으로 초기화

리터럴(Literal) : 체력 100 처럼 직접 적은 값을 리터럴이라고 한다.

char : UTF-16 코드 단위 하나

문자열 보간 : 앞에 $을 넣고 {변수이름}을 적으면 섞을 수 있다.

# 프로그램의 흐름
- 중괄호는 한 덩어리의 시작과 끝
namespace : 관련 형식의 이름을 묶음
- 김동훈(서울) 김동훈(부산) : 네!
- 이름이 같으면 컴퓨터 입장에서 어떻게 구별해? 에러! 해결하기 위해서 존재한다.
- 코드는 혼자 작업하는게 아니다. 게임만들때 필요한 명사를 말해보세요. 캐릭터, 배경, 그래픽 / A가 만든 Character B가 만든 Character

static class Program : static은 정적스택.

static void Main() : Main함수는 코드의 시작점

Console.WriteLine : 텍스트 출력

- namespace는 실행 명령이 아닙니다.
using System; : using System;은 System 네임스페이스에 있는 형식을 짧은 이름으로 사용하게 하는 using 지시문이다.
System.Console.WriteLine을 Console.WriteLine으로 쓸수 있게 해주는 것이다.

- Program 클래스와 static을 나누어 읽기
[클래스는 메서드가 속하는 형식이다]
클래스에서 출력문을 적는 것이 아닌 클래스 안에 있는 메서드에서 출력문을 적는 것이 컴파일되는 방식이다.

[static void Main()이 뜻하는 것.]
- static : Program 객체를 만들지 않고 호출할 수 있는 메서드
- void : 호출한 쪽에 결과값을 반환하지 않음
- Main : 명시적인 실행 진입점으로 사용할 메서드 이름

- 클래스의 static과 Main의 스태틱은 별도이다 : Class에 static을 적용하지 않아도 static void Main()이 유효하다.
- 정적 클래스 안에 일반적인 인스턴스 메서드를 선언하면 오류가 발생합니다 ?? :
