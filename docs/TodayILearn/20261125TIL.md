## 📖 배운 내용
### 1. 배열의 선언
- 배열 문법의 선언 방법을 학습했다.

```csharp
int scores = { 10, 20, 30 };
int scores[] = { 10, 20, 30 };
```
- 위 두 줄 방식으로 배열을 선언했지만 컴파일 오류가 떴다. 해결 방법은 아래와 같이 작성해야 했다.

```csharp
int[] scores = { 10, 20, 30 };
```
- 이유를 몰라서 공부해 본 결과 배열은 `System.Array`라는 클래스를 상속받으며 배열로 지정하는 순간 참조타입으로 바뀐다고 한다.
- 그렇다면 `scores`와 `scores2` 둘 다 타입을 `int[]`형으로 하면 값이 덮어씌우기가 되는지 궁금했다.

```csharp
int[] scores = { 10, 20, 30 };
int[] scores2 = { 1, 2, 3 };

Console.WriteLine(scores[1]);
Console.WriteLine(scores2[1]);
```
- 결과는 덮어씌우기가 되지 않고 각각 값이 달랐다.

```csharp
int[] scores2 = new int[] { 1, 2, 3 };
```
- 알고 봤더니 C#에서는 배열을 만들 때 중괄호(`{ }`)를 쓰는 순간 `new`를 한다고 한다. 그래서 실제로 `int[] scores2 = new int[] { 1, 2, 3 };`을 입력해 봤더니 똑같이 컴파일 되는 것을 확인했다.

### 2. `foreach`문 반복 변수에 기존 변수(멤버 변수 포함)를 사용할 수 없는 이유
- `foreach (int value in scores2)` 형태에서 `int value` 대신 이미 선언된 `result`나 멤버 변수를 넣으면 컴파일 오류가 발생한다.

```csharp
// ❌ 기존 변수 재사용 불가 (컴파일 에러)
foreach (result in scores2) { }

// ⭕ 반드시 새로운 반복 변수를 선언해야 함
foreach (int value in scores2)
{
    result = value; // 외부 변수에 값을 담고 싶다면 루프 내부에서 대입
    Console.WriteLine(\$"value : {value}");
}
```
- **문법적 강제**: 일반 `for`문과 달리 `foreach`문은 `foreach (타입 변수명 in 컬렉션)` 형태로 **반복문 전용 지역 변수를 새로 선언**하는 문법이다.
- **읽기 전용 보호**: `foreach`의 반복 변수는 컬렉션을 안전하게 순회하기 위해 읽기 전용(Read-Only)으로 취급된다. 외부 변수나 멤버 변수를 직접 연결해 의도치 않게 값이 변경되는 부작용(Side Effect)을 막기 위해 언어 차원에서 제한하고 있다.

### 3. `while`문에서 `result`가 50보다 크면 중지되게 했지만 무한반복이 되는 이유
- **`while`문 안에 `for`문이 있으면 다 끝나기 전까지는 결과를 집계하지 않는다.**

```csharp
// foreach문을 통해 float 10, 20, 30을 대입
// while문을 통해 50이 될때까지 반복
// 배열 길이로 평균값을 나누고 그 값을 출력

int[] scores = { 10, 20, 30 };
int result = 0;

while (result < 50)
{
    for (int i = 0; i < scores.Length; ++i)
    {
        result += scores[i];
    }
    result = result / scores.Length;
    Console.WriteLine(\$"평균값 : {result}");
}
```
- 디버그 결과 평균값이 `29`가 되어 즉 `50`보다 커지지 않아서 무한반복이 되었다.

## 🔥 트러블슈팅
### 1. `while`문 내부 `for`문 평균 계산 무한반복 오류
- **문제**: `while (result < 50)` 조건에서 평균값이 `50`을 넘지 못해 무한반복이 발생했다.
- **원인**: `while`문에 `for`문이 있을 경우 `for`문이 끝나기 전에는 결과를 집계하지 않으며, 디버그 결과 평균값이 `29`로 수렴하여 `50`보다 커지지 않았기 때문이다.
- **해결**: `29`보다 작을 때까지(`result < 29`)로 조건을 변경하여 디버그를 해본 결과 무한반복되지 않고 정상적으로 해결되었다.

```csharp
int[] scores = { 10, 20, 30 };
int result = 0;

while (result < 29)
{
    for (int i = 0; i < scores.Length; ++i)
    {
        result += scores[i];
    }
    result = result / scores.Length;
    Console.WriteLine(\$"평균값 : {result}");
}
```

## 💡 느낀 점
- C#에서 배열로 선언된 순간 자료형이 참조타입이 되며 변수 자체는 참조타입을 가리키지만 변수에 배열의 번호를 입력하면 값을 꺼내온다.
- C#은 `System.Array` 클래스를 상속받아 배열을 구현할 수 있으며 `new`를 입력하지 않아도 자동으로 heap에 동적 주소를 할당한다.
- 배열이 참조타입이기에 변수에다가 `[]`를 쓰는 것이 아닌 자료형 쪽에 `[]`를 써서 구현해야 함을 이해했다.
- `foreach`문은 순회 중 데이터가 임의로 변하는 것을 막기 위해 읽기 전용 새 지역 변수만 허용한다는 점을 알게 되었다.
