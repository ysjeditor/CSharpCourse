# 게임루프

이벤트는 내가 호출할 때마다 실행되는 것이다.

그래서 이벤트 구동과 실제 시간에서 차이가 날 수가 있다.

그래서 입력이 있든 없든 스스로 계속 도는 반복문

이것이 게임 루프(Game Loop)이다.

## 무엇을
## 게임 루프의 3요소

1. 입력(Input)
2. 갱신(Update)
3. 렌더(Render)

이 3가지를 프레임(한 바퀴)으로 표현한 것이다.

## 무슨 문제가 발생했나요?
- 플레이어가 사물로 다가갈 수록 사물을 표현하고 있는 문자가 다음과 같은 순서로 바뀌는데 :, +, %, @, # 이것때문에 어지러움이 느껴졌다.


## 왜
- 원근감을 표현하기위해 코드 자체에서 벽의 질감을 distance를 통한 거리에 따라서 문양이 바뀌도록 설정해놓았다.


## 실습
- 여러가지의 문자 대신 한가지의 문자만 사용하도록 하여 수정하였다.
